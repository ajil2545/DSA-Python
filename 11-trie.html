Trees

A tree where each path from root to a node represents a prefix. Powers autocomplete, spell-check, and IP routing.

INSERT
O(m)
SEARCH
O(m)
PREFIX SEARCH

CONCEPT 01

Trie Structure

INSERTING: "cat", "car", "card", "care", "bat"
  root
  ├── c
  │   └── a
  │       ├── t  [end]        → "cat"
  │       └── r  [end]        → "car"
  │           ├── d  [end]    → "card"
  │           └── e  [end]    → "care"
  └── b
      └── a
          └── t  [end]        → "bat"

Each node stores its children in a dict mapping a character to the child node, plus a flag saying whether a word ends here. Using __slots__ keeps millions of small nodes lighter in memory.

PYTHON — Trie Implementation
from typing import Dict

class TrieNode:
    __slots__ = ("children", "is_end")

    def __init__(self):
        self.children: Dict[str, "TrieNode"] = {}  # char → TrieNode
        self.is_end = False                        # marks end of a word

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()  # create new node
            node = node.children[ch]            # move down
        node.is_end = True                      # mark word end

    def _walk(self, s: str):
        """Follow s from the root; return the last node or None."""
        node = self.root
        for ch in s:
            node = node.children.get(ch)
            if node is None:
                return None
        return node

    def search(self, word: str) -> bool:
        node = self._walk(word)
        return node is not None and node.is_end  # must be a complete word

    def starts_with(self, prefix: str) -> bool:
        return self._walk(prefix) is not None    # prefix exists (is_end doesn't matter)

trie = Trie()
trie.insert("cat")
print(trie.search("cat"))       # True
print(trie.search("ca"))        # False (not a full word)
print(trie.starts_with("ca"))   # True (prefix exists)
Pythonic shortcut: node.children.setdefault(ch, TrieNode()) replaces the "if missing, create" two-liner in insert — though it builds a throwaway TrieNode on every call, so the explicit if is slightly faster.
TECHNIQUE 01

The Nested-dict Trie (defaultdict Trick)

In interviews you often don't need a node class at all. A trie can be dicts nested inside dicts, with a special key such as "$" marking the end of a word. A recursive defaultdict creates child levels automatically, so insert becomes a one-line loop.

PYTHON — dict-of-dicts Trie
from collections import defaultdict

END = "$"   # sentinel key: "a word ends here"

def make_trie():
    return defaultdict(make_trie)   # every missing child is itself a new trie

def insert(root, word):
    node = root
    for ch in word:
        node = node[ch]             # auto-creates the child level
    node[END] = True

def find(root, s):
    node = root
    for ch in s:
        if ch not in node:          # use `in` — indexing would CREATE the key!
            return None
        node = node[ch]
    return node

def words_with_prefix(root, prefix):
    """Autocomplete: collect every word below the prefix node (DFS)."""
    node, out = find(root, prefix), []

    def dfs(n, path):
        for ch, child in n.items():
            if ch == END:
                out.append(prefix + path)
            else:
                dfs(child, path + ch)

    if node is not None:
        dfs(node, "")
    return sorted(out)

root = make_trie()
for w in ["cat", "car", "card", "care", "bat"]:
    insert(root, w)

print(END in find(root, "car"))        # True  — "car" is a word
print(END in find(root, "ca"))         # False — only a prefix
print(find(root, "dog") is None)       # True  — not even a prefix
print(words_with_prefix(root, "car"))  # ['car', 'card', 'care']
Watch out: with a defaultdict, writing node[ch] during a search silently inserts empty branches. Always test membership with ch in node (or node.get(ch)) when you are only reading.
