Linked Lists

A chain of nodes where each node holds data and a reference to the next. No random access — but O(1) insert/delete at known positions.

ACCESS
O(n)
SEARCH
O(n)
INSERT HEAD
O(1)
DELETE HEAD
O(1)
CONCEPT 01

The Node & Singly Linked List

Each node holds a value and a next reference. The last node's next is None. The head is your only entry point — lose it, and you lose the whole list. In Python every variable is a reference to an object, so node.next = other just points at other; nothing is copied.

SINGLY LINKED LIST STRUCTURE
  head
   ↓
  [1 | •]──→ [2 | •]──→ [3 | •]──→ [4 | None]
   val  next   val  next   val  next   val
PYTHON — ListNode & LinkedList Class
from typing import Optional

class ListNode:
    __slots__ = ("val", "next")          # fixed attributes → less memory per node

    def __init__(self, val: int = 0, next: Optional["ListNode"] = None):
        self.val = val
        self.next = next                   # None marks the end of the list

    def __repr__(self) -> str:             # what print() and the debugger show
        return f"ListNode({self.val})"


class LinkedList:
    def __init__(self):
        self.head: Optional[ListNode] = None

    # Add to front — O(1)
    def prepend(self, val: int) -> None:
        self.head = ListNode(val, self.head)

    # Add to end — O(n)
    def append(self, val: int) -> None:
        node = ListNode(val)
        if self.head is None:
            self.head = node
            return

        cur = self.head
        while cur.next:                      # walk to the last node
            cur = cur.next
        cur.next = node

    # Make the list iterable — a generator yields one value at a time
    def __iter__(self):
        cur = self.head
        while cur:
            yield cur.val
            cur = cur.next

    def __repr__(self) -> str:
        return " -> ".join(str(v) for v in self)


lst = LinkedList()
lst.append(1); lst.append(2); lst.append(3)
print(lst)              # 1 -> 2 -> 3
lst.prepend(0)
print(list(lst))        # [0, 1, 2, 3]   (works because of __iter__)
print(lst.head)         # ListNode(0)    (works because of __repr__)
Python's list is not a linked list — it's a dynamic array (O(1) index, O(n) insert at front). When you need O(1) adds/removes at both ends, use collections.deque, which is implemented as a doubly linked list of blocks. You still need to hand-build nodes for interview problems like the ones below.
TECHNIQUE 01

Reversing a Linked List

The #1 linked list interview question. Use three pointers: prev, curr, nxt. Walk through, flipping each next pointer backward.

REVERSAL STEP-BY-STEP
  Start:  prev=None   [1]→[2]→[3]→None
                      curr

  Step 1: None←[1]   [2]→[3]→None
               prev  curr

  Step 2: None←[1]←[2]   [3]→None
                   prev  curr

  Step 3: None←[1]←[2]←[3]   None
                       prev  curr   → loop ends, return prev (new head)
PYTHON — Reverse Linked List
def reverse_list(head: Optional[ListNode]) -> Optional[ListNode]:
    prev = None
    curr = head

    while curr is not None:
        nxt = curr.next    # save next before we overwrite it (nxt: don't shadow built-in next())
        curr.next = prev   # flip the pointer
        prev = curr        # advance prev
        curr = nxt         # advance curr

    return prev            # prev is now the new head

head = ListNode(1, ListNode(2, ListNode(3)))   # 1 → 2 → 3
new_head = reverse_list(head)
print(new_head, new_head.next, new_head.next.next)
# ListNode(3) ListNode(2) ListNode(1)
TECHNIQUE 02

Fast & Slow Pointers

Two pointers moving at different speeds. The fast pointer moves 2 steps, slow moves 1. When fast reaches the end, slow is at the middle. Also detects cycles (Floyd's algorithm). Compare nodes with is (same object), not == (equal value).

EXAMPLE — Detect Cycle (Floyd's)
def has_cycle(head: Optional[ListNode]) -> bool:
    slow = fast = head

    while fast is not None and fast.next is not None:
        slow = slow.next           # move 1 step
        fast = fast.next.next      # move 2 steps

        if slow is fast:           # same node object → they met
            return True            # cycle!

    return False                   # fast hit None → no cycle


# Find middle of linked list
def find_middle(head: Optional[ListNode]) -> Optional[ListNode]:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow                    # slow is at the middle


head = ListNode(1, ListNode(2, ListNode(3, ListNode(4, ListNode(5)))))
print(find_middle(head))           # ListNode(3)
print(has_cycle(head))             # False
head.next.next.next.next.next = head.next   # tail (5) → node 2: creates a cycle
print(has_cycle(head))             # True
TECHNIQUE 03

The Dummy (Sentinel) Node

Many bugs come from the special case "what if I have to change the head?". Put a fake dummy node in front of the real head: now every real node — including the head — has a predecessor, so one code path handles everything. Return dummy.next at the end.

DUMMY NODE
  dummy → [1] → [1] → [2] → [1] → [3] → None      remove all 1s
  prev
  ...
  dummy → [2] → [3] → None                        return dummy.next
EXAMPLE — Remove All Nodes With a Value
from typing import List

def remove_value(head: Optional[ListNode], target: int) -> Optional[ListNode]:
    dummy = ListNode(0, head)       # fake node BEFORE the real head
    prev = dummy

    while prev.next:
        if prev.next.val == target:
            prev.next = prev.next.next  # unlink — works even when it's the head!
        else:
            prev = prev.next

    return dummy.next                # the real (possibly new) head


def to_list(head: Optional[ListNode]) -> List[int]:   # handy debug helper
    out = []
    while head:
        out.append(head.val)
        head = head.next
    return out

head = ListNode(1, ListNode(1, ListNode(2, ListNode(1, ListNode(3)))))
print(to_list(remove_value(head, 1)))   # [2, 3]
CONCEPT 02

Doubly Linked List

Each node has both next AND prev pointers — you can traverse in both directions. Used inside CPython's collections.OrderedDict (to track order), collections.deque, and functools.lru_cache — and in every hand-written LRU Cache.

PYTHON — Doubly Linked Node
class DNode:
    __slots__ = ("val", "prev", "next")

    def __init__(self, val: int):
        self.val = val
        self.next: Optional["DNode"] = None
        self.prev: Optional["DNode"] = None   # ← extra pointer

# Structure:
# None ←[1]⇄[2]⇄[3]→ None
#       head         tail
