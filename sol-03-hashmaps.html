Hash map problems — the O(1) lookup superpower of dict, set, Counter and defaultdict in action.

01Top K Frequent ElementsMEDIUM
Think: Count frequencies with a Counter. Then sort by frequency and take the top k. Alternative (bucket sort approach): since frequency can't exceed n, use the list index as the frequency bucket — O(n) time.
Time: O(n)
Space: O(n)
SOLUTION — Bucket Sort (O(n))
from collections import Counter
from typing import List

def top_k_frequent(nums: List[int], k: int) -> List[int]:
    # Step 1: Count each number's frequency
    freq = Counter(nums)

    # Step 2: Bucket by frequency (index = frequency)
    # e.g. buckets[3] = [numbers that appear exactly 3 times]
    buckets = [[] for _ in range(len(nums) + 1)]   # NOT [[]] * n — that shares ONE list!
    for num, count in freq.items():
        buckets[count].append(num)

    # Step 3: Collect from highest frequency down until we have k elements
    result = []
    for i in range(len(buckets) - 1, -1, -1):
        result.extend(buckets[i])
        if len(result) >= k:
            break

    return result[:k]

print(top_k_frequent([1, 1, 1, 2, 2, 3], 2))   # [1, 2]

# Interview shortcut: most_common(k) uses a heap internally → O(n log k)
print([n for n, _ in Counter([1, 1, 1, 2, 2, 3]).most_common(2)])   # [1, 2]
02Longest Consecutive SequenceMEDIUM
Think: Put all numbers in a set. For each number, only START counting if it's the beginning of a sequence (num-1 is NOT in the set). Then count upward: num+1, num+2... This avoids redundant counting and stays O(n).
1
Add all numbers to a set for O(1) in lookup.
2
For each number, skip it if num-1 exists (it's not a sequence start).
3
If it IS a start, count how far the streak goes: num+1, num+2, etc.
Time: O(n)
Space: O(n)
SOLUTION
from typing import List

def longest_consecutive(nums: List[int]) -> int:
    num_set = set(nums)
    longest = 0

    for num in num_set:
        # Only start counting from the beginning of a sequence
        if num - 1 not in num_set:
            current = num
            streak = 1

            # Count upward as long as the next number exists
            while current + 1 in num_set:
                current += 1
                streak += 1

            longest = max(longest, streak)

    return longest

print(longest_consecutive([100, 4, 200, 1, 3, 2]))   # 4 (1,2,3,4)
03Subarray Sum Equals KMEDIUM
Think: Prefix sum + hash map. If prefix[j] - prefix[i] = k, then subarray i→j sums to k. So for each prefix sum, check if (current_sum - k) was seen before. Count those occurrences.
1
Build running prefix sum as you iterate.
2
For each prefix sum, check if (total - k) exists in our dict.
3
If yes, that many subarrays ending here sum to k. Add that count.
4
Store current prefix sum in the dict.
Time: O(n)
Space: O(n)
SOLUTION
from collections import defaultdict
from typing import List

def subarray_sum(nums: List[int], k: int) -> int:
    # prefix sum → how many times it has appeared
    prefix_counts = defaultdict(int)
    prefix_counts[0] = 1        # empty prefix (sum=0) appears once

    total = count = 0           # don't call it `sum` — that shadows the built-in

    for num in nums:
        total += num

        # If (total - k) was seen before, those subarrays sum to k.
        # .get() so we don't INSERT missing keys into the defaultdict
        count += prefix_counts.get(total - k, 0)

        # Record this prefix sum
        prefix_counts[total] += 1

    return count

print(subarray_sum([1, 1, 1], 2))   # 2  ([1,1] at 0-1 and 1-2)
print(subarray_sum([1, 2, 3], 3))   # 2  ([1,2] and [3])
