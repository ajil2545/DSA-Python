Five warm-ups that train the core loop patterns — plus a “guess the complexity” quiz to sharpen your Big-O instincts.

01Find Max Without max()EASY
Think: Keep a running “best so far”. Start it at the first element (not 0 — the list may be all negative) and compare every other element against it. Decide up front what an empty list should return.
1
Handle the empty list (return None, or raise ValueError like the built-in does).
2
Set best = nums[0].
3
Loop over the elements; whenever x > best, replace best.
4
Return best.
Time: O(n)
Space: O(1)
SOLUTION
from typing import List, Optional

def find_max(nums: List[int]) -> Optional[int]:
    if not nums:
        return None
    best = nums[0]               # NOT 0: [-5, -2] must return -2
    for x in nums:               # re-checking nums[0] is harmless; nums[1:] would copy (O(n) space)
        if x > best:
            best = x
    return best

def find_max_index(nums: List[int]) -> int:
    best_i = 0
    for i in range(1, len(nums)):
        if nums[i] > nums[best_i]:
            best_i = i
    return best_i

print(find_max([3, 9, 2, 7]))       # 9
print(find_max([-5, -2, -9]))       # -2
print(find_max([]))                 # None
print(find_max_index([3, 9, 2, 9])) # 1   first occurrence wins with >
Built-in: max(nums) does the same O(n) loop in C; max(nums, default=None) avoids the error on empty input.
02Count FrequenciesEASY
Think: Walk the input once and keep a dict from item → count. d.get(x, 0) + 1 avoids a KeyError the first time you see an item. Then learn the shortcuts: defaultdict(int) and Counter.
1
Create an empty dict counts.
2
For each item: counts[x] = counts.get(x, 0) + 1.
3
Return the dict. To find the most common, scan for the max value (or use Counter.most_common).
Time: O(n)
Space: O(k) for k distinct items
SOLUTION — Plain dict
from typing import Dict, Hashable, Iterable

def count_frequencies(items: Iterable[Hashable]) -> Dict[Hashable, int]:
    counts = {}
    for x in items:
        counts[x] = counts.get(x, 0) + 1
    return counts

freq = count_frequencies("banana")
print(freq)                          # {'b': 1, 'a': 3, 'n': 2}
print(max(freq, key=freq.get))       # a
print(count_frequencies([3, 1, 3]))  # {3: 2, 1: 1}
SOLUTION — collections Shortcuts
from collections import Counter, defaultdict

counts = defaultdict(int)            # missing keys start at 0
for word in "the cat and the hat".split():
    counts[word] += 1
print(dict(counts))                  # {'the': 2, 'cat': 1, 'and': 1, 'hat': 1}

c = Counter("banana")
print(c)                             # Counter({'a': 3, 'n': 2, 'b': 1})
print(c.most_common(1))              # [('a', 3)]
print(c["z"])                        # 0   missing keys count as 0
print(Counter("listen") == Counter("silent"))   # True   anagram check
03FizzBuzzEASY
Think: For 1..n: multiples of 15 → “FizzBuzz”, of 3 → “Fizz”, of 5 → “Buzz”, otherwise the number. The only trap is order: test 15 (both) first, or build the string piece by piece so the order can't go wrong.
1
Loop i over range(1, n + 1) (stop is exclusive!).
2
Build s: add “Fizz” if i % 3 == 0, add “Buzz” if i % 5 == 0.
3
Append s or str(i) — an empty string is falsy, so or falls back to the number.
Time: O(n)
Space: O(n) for the output list
SOLUTION
from typing import List

def fizzbuzz(n: int) -> List[str]:
    out = []
    for i in range(1, n + 1):
        s = ""
        if i % 3 == 0:
            s += "Fizz"
        if i % 5 == 0:
            s += "Buzz"
        out.append(s or str(i))
    return out

def fizzbuzz_classic(n: int) -> List[str]:
    out = []
    for i in range(1, n + 1):
        if i % 15 == 0:          # check the combined case FIRST
            out.append("FizzBuzz")
        elif i % 3 == 0:
            out.append("Fizz")
        elif i % 5 == 0:
            out.append("Buzz")
        else:
            out.append(str(i))
    return out

print(fizzbuzz(15))
# ['1', '2', 'Fizz', '4', 'Buzz', 'Fizz', '7', '8', 'Fizz', 'Buzz', '11', 'Fizz', '13', '14', 'FizzBuzz']
print(fizzbuzz(15) == fizzbuzz_classic(15))   # True
# one print call for all lines: 1, 2, Fizz, 4, Buzz on separate lines
print("\n".join(fizzbuzz(5)))
04Reverse a List In PlaceEASY
Think: “In place” means O(1) extra space — you may not build a second list. Use two pointers: one at each end, swap, move both inward, stop when they meet. Python's tuple swap a[i], a[j] = a[j], a[i] needs no temp variable.
1
i = 0, j = len(nums) - 1.
2
While i < j: swap nums[i] and nums[j].
3
i += 1, j -= 1. Return nothing — the caller's list itself changed.
Time: O(n)
Space: O(1)
SOLUTION — Two Pointers
from typing import List

def reverse_in_place(nums: List[int]) -> None:
    i, j = 0, len(nums) - 1
    while i < j:
        nums[i], nums[j] = nums[j], nums[i]
        i += 1
        j -= 1

a = [1, 2, 3, 4, 5]
reverse_in_place(a)
print(a)                 # [5, 4, 3, 2, 1]
b = [1, 2]
reverse_in_place(b)
print(b)                 # [2, 1]
empty = []
reverse_in_place(empty)  # loop never runs: i=0, j=-1
print(empty)             # []
COMPARE — Built-ins and Their Space Cost
a = [1, 2, 3]
a.reverse()              # in place, O(1) extra space, returns None
print(a)                 # [3, 2, 1]

b = [1, 2, 3]
c = b[::-1]              # NEW list: O(n) extra space, b unchanged
print(b, c)              # [1, 2, 3] [3, 2, 1]

b[:] = b[::-1]           # replaces contents of the same object (still O(n) temp space)
print(b)                 # [3, 2, 1]
print(list(reversed([1, 2, 3])))   # [3, 2, 1]   reversed() is a lazy iterator
05Second Largest ElementEASY
Think: Sorting works (sorted(set(nums))[-2]) but costs O(n log n). One pass is enough: track first and second. When a new maximum arrives, the old maximum is demoted to second. Decide whether duplicates count — here we want the second largest distinct value, and return None if it doesn't exist.
1
Start first = second = float('-inf').
2
If x > first: second, first = first, x (demote, then promote).
3
Elif first > x > second: second = x (strict, so duplicates of the max are ignored).
4
Return None if second is still -inf.
Time: O(n)
Space: O(1)
SOLUTION — One Pass
from typing import List, Optional

def second_largest(nums: List[int]) -> Optional[int]:
    first = second = float("-inf")
    for x in nums:
        if x > first:
            second, first = first, x     # old max becomes second
        elif first > x > second:         # chained comparison
            second = x
    return None if second == float("-inf") else second

print(second_largest([5, 1, 5, 3]))   # 3
print(second_largest([2, 8, 6, 8]))   # 6
print(second_largest([-1, -4]))       # -4
print(second_largest([7, 7]))         # None
print(second_largest([]))             # None
ALTERNATIVES — Shorter but Slower or More Memory
import heapq

nums = [5, 1, 5, 3]
distinct = sorted(set(nums))                  # O(n log n) time, O(n) space
print(distinct[-2] if len(distinct) > 1 else None)   # 3
print(heapq.nlargest(2, set(nums))[-1])       # 3   O(n log k) with k = 2
BONUS

Guess the Complexity

Decide the time complexity of each function before you open the answer. Look for loops, halving, and hidden O(n) operations inside loops.

Q1Inner Loop With a Fixed SizeGUESS
WHAT IS THE TIME COMPLEXITY?
def mystery_a(nums):
    total = 0
    for x in nums:
        for y in nums[:3]:
            total += x * y
    return total

print(mystery_a([1, 2, 3, 4]))   # 60
▸ Show answer
O(n) — the inner loop runs at most 3 times no matter how big n is, and nums[:3] copies at most 3 items. O(3n) = O(n). Nested loops only multiply when both depend on n.
Q2Doubling CounterGUESS
WHAT IS THE TIME COMPLEXITY?
def mystery_b(n):
    count = 0
    i = 1
    while i < n:
        i *= 2
        count += 1
    return count

print(mystery_b(1000))   # 10
▸ Show answer
O(log n) — i doubles each step: 1, 2, 4, … reaches n after log₂ n iterations. Any loop that multiplies or divides its variable by a constant is logarithmic.
Q3Dedupe With a ListGUESS
WHAT IS THE TIME COMPLEXITY?
def mystery_c(nums):
    result = []
    for x in nums:
        if x not in result:
            result.append(x)
    return result

print(mystery_c([1, 2, 1, 3, 2]))   # [1, 2, 3]
▸ Show answer
O(n²) — x not in result scans a list, which is O(n). Inside a loop of n iterations that's O(n²) when most items are distinct. Fix: keep a parallel set for membership (or list(dict.fromkeys(nums))) → O(n).
Q4Sort, Then One PassGUESS
WHAT IS THE TIME COMPLEXITY?
def mystery_d(nums):
    nums = sorted(nums)
    best = 0
    for i in range(1, len(nums)):
        best = max(best, nums[i] - nums[i - 1])
    return best

print(mystery_d([3, 9, 1, 4]))   # 5
▸ Show answer
O(n log n) — sequential steps add: O(n log n) for the sort + O(n) for the loop = O(n log n). The dominant term wins. Space is O(n) because sorted returns a new list.
Q5Building a String BackwardsGUESS
WHAT IS THE TIME COMPLEXITY?
def mystery_e(s):
    out = ""
    for ch in s:
        out = ch + out
    return out

print(mystery_e("hello"))   # olleh
▸ Show answer
O(n²) — strings are immutable, so ch + out creates a brand-new string of length 1, 2, 3, … n: 1 + 2 + … + n = O(n²) character copies. Fix: s[::-1], or collect characters in a list and ''.join(reversed(chars)) → O(n).
Scorecard: 5/5 — you're ready for Arrays. Missed Q3 or Q5? Re-read “Spot the Hidden Loop” on the lesson page; those hidden O(n) operations are the most common source of Time Limit Exceeded in Python.
