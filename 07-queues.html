Note: list.pop(0) is O(n) — every remaining element shifts left by one. *Dequeue is O(1) only with collections.deque, which is a doubly-linked block list with O(1) appends and pops at both ends. Always use deque for queues.
CONCEPT 01

Queue in Python

Add to the back (enqueue), remove from the front (dequeue). In Python, use collections.deque: append() to enqueue and popleft() to dequeue — both O(1). A plain list with pop(0) works but is O(n) per dequeue, turning a BFS into O(n²).

QUEUE: FIRST IN, FIRST OUT
  popleft() ←  [  A  ] [  B  ] [  C  ]  ← append()
               front                back
  popleft() removes A first (it got in first)
PYTHON — collections.deque
from collections import deque

q = deque()
q.append("A")        # enqueue → deque(['A'])
q.append("B")
q.append("C")        # deque(['A', 'B', 'C'])
print(q.popleft())   # dequeue → A   (O(1))
print(q[0])          # peek front → B
print(len(q))        # 2

# Bonus deque features
q.appendleft("Z")    # push to front → deque(['Z', 'B', 'C'])
q.rotate(1)          # rotate right → deque(['C', 'Z', 'B'])
print(q)

recent = deque(maxlen=3)   # bounded: oldest item auto-drops
for x in range(5):
    recent.append(x)
print(recent)        # deque([2, 3, 4], maxlen=3)
PYTHON — Queue Class
from collections import deque
from typing import Any

class Queue:
    def __init__(self) -> None:
        self.items = deque()

    def enqueue(self, val: Any) -> None:
        self.items.append(val)

    def dequeue(self) -> Any:
        return self.items.popleft()   # O(1); list.pop(0) would be O(n)

    def front(self) -> Any:
        return self.items[0]

    def is_empty(self) -> bool:
        return not self.items

    def __len__(self) -> int:
        return len(self.items)

qu = Queue()
qu.enqueue(1); qu.enqueue(2)
print(qu.dequeue(), qu.front(), len(qu))  # 1 2 1
queue.Queue is not for DSA: the standard library's queue.Queue is a thread-safe queue for producer/consumer code between threads. Its locking makes it much slower, and it has no indexing or iteration. For algorithms (BFS, sliding windows, scheduling simulations) use collections.deque.
TECHNIQUE 01

BFS with a Queue

Breadth-First Search explores nodes level by level — all neighbors first, then their neighbors. A queue is the natural tool: enqueue neighbors, process in order. Because nodes are reached in order of distance, BFS finds shortest paths in unweighted graphs and grids.

EXAMPLE — BFS on a Binary Tree (Level Order)
from collections import deque
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def level_order(root: Optional[TreeNode]) -> List[List[int]]:
    if not root:
        return []
    result = []
    queue = deque([root])

    while queue:
        level = []
        for _ in range(len(queue)):  # nodes at current level
            node = queue.popleft()       # dequeue — O(1)
            level.append(node.val)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

        result.append(level)

    return result

root = TreeNode(1,
                TreeNode(2, TreeNode(4), TreeNode(5)),
                TreeNode(3, TreeNode(6), TreeNode(7)))
print(level_order(root))  # [[1], [2, 3], [4, 5, 6, 7]]
