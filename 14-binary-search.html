Binary Search

Halve your search space every step. O(log n) on sorted data. Deceptively tricky to implement perfectly — master the boundaries.

SEARCH
O(log n)
SPACE
O(1)
REQUIREMENT
SORTED
CONCEPT 01

The Classic Binary Search

Three variables: lo, hi, mid. Compare arr[mid] with target — if too small, move lo up; if too big, move hi down. Repeat until found or exhausted.

SEARCH FOR 9 IN [1,3,5,7,9,11,13]
  [1, 3, 5, 7, 9, 11, 13]
   lo      mid        hi
  lo=0, hi=6 → mid=3: arr[3]=7 < 9 → lo = mid+1

  [1, 3, 5, 7, 9, 11, 13]
               lo mid hi
  lo=4, hi=6 → mid=5: arr[5]=11 > 9 → hi = mid-1

  [1, 3, 5, 7, 9, 11, 13]
               ↑ lo = hi = mid = 4
  arr[4]=9 == 9  ✓  Found at index 4!
PYTHON — Binary Search
from typing import List


def binary_search(arr: List[int], target: int) -> int:
    lo, hi = 0, len(arr) - 1

    while lo <= hi:            # ← <= not <
        mid = (lo + hi) // 2    # // is floor division → always an int

        if arr[mid] == target:
            return mid           # found!
        elif arr[mid] < target:
            lo = mid + 1         # search right half
        else:
            hi = mid - 1         # search left half

    return -1  # not found


print(binary_search([1, 3, 5, 7, 9], 7))  # 3 (index)
Common bugs: using lo < hi instead of lo <= hi, using lo = mid instead of lo = mid + 1, and writing / instead of // — in Python 3, (lo + hi) / 2 returns a float and arr[3.0] raises TypeError.
No overflow in Python: Python ints are arbitrary-precision, so mid = (lo + hi) // 2 can never overflow. The lo + (hi - lo) // 2 form you see in Java/C++ solutions is only needed there because of fixed-width 32-bit ints — it's harmless in Python, but not required.
CONCEPT 02

The bisect Module — Binary Search Built In

Python's standard library ships a battle-tested binary search: bisect. bisect_left(a, x) returns the first index where x could be inserted keeping a sorted (i.e. the first element >= x); bisect_right(a, x) returns the index just past the last x (first element > x). insort(a, x) inserts in sorted position. Use it in real code, and as a cross-check for your hand-written version.

PYTHON — bisect_left / bisect_right / insort
from bisect import bisect_left, bisect_right, insort

a = [1, 3, 5, 5, 5, 7, 9]

print(bisect_left(a, 5))    # 2  ← first 5
print(bisect_right(a, 5))   # 5  ← one past the last 5
print(bisect_right(a, 5) - bisect_left(a, 5))  # 3  ← count of 5s in O(log n)


def index_of(a, x) -> int:
    """Exact-match search built on bisect_left."""
    i = bisect_left(a, x)
    return i if i < len(a) and a[i] == x else -1


print(index_of([1, 3, 5, 7, 9], 7))  # 3  — same answer as binary_search
print(index_of([1, 3, 5, 7, 9], 4))  # -1

nums = [1, 4, 9]
insort(nums, 5)                 # O(log n) search + O(n) shift
print(nums)                     # [1, 4, 5, 9]
Interview tip: Interviewers usually want to see you write the loop yourself — but mentioning bisect shows you know the language, and it's the fastest way to test your own implementation: assert binary_search(a, x) == index_of(a, x) for many random inputs.
TECHNIQUE 01

Search in Rotated Sorted Array

A sorted array that's been rotated (e.g., [4,5,6,7,0,1,2]). At least one half is always sorted — determine which half, then binary search the sorted half.

PYTHON — Search in Rotated Sorted Array
from typing import List


def search_rotated(nums: List[int], target: int) -> int:
    lo, hi = 0, len(nums) - 1

    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid

        # Is LEFT half sorted?
        if nums[lo] <= nums[mid]:
            # Is target in the sorted left half? (chained comparison!)
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1  # search left
            else:
                lo = mid + 1  # search right
        else:
            # RIGHT half is sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1  # search right
            else:
                hi = mid - 1  # search left

    return -1


print(search_rotated([4, 5, 6, 7, 0, 1, 2], 0))  # 4
Python idiom: a <= x < b is a chained comparison — it means a <= x and x < b. Perfect for "is target inside this range?" checks.
TECHNIQUE 02

Binary Search on Answer

Sometimes you don't search in an array — you binary search on the answer space. "Find the minimum speed such that X is possible" — if speed k works, k+1 also works, so binary search on k. In Python the condition is just a function (or lambda) you pass in.

PYTHON — Search on Answer Space
from typing import Callable


# Template: find minimum value where condition(value) is True
def find_min(lo: int, hi: int, condition: Callable[[int], bool]) -> int:
    result = hi

    while lo <= hi:
        mid = (lo + hi) // 2

        if condition(mid):
            result = mid     # this works, but try smaller
            hi = mid - 1
        else:
            lo = mid + 1     # too small, try bigger

    return result


# Example use: smallest x in [0, 100] with x * x >= 50
print(find_min(0, 100, lambda x: x * x >= 50))  # 8
