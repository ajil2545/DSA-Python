Trie Solutions

Prefix trees in Python — a dict of children per node, an is_end flag, and DFS when the pattern branches.

01Implement Trie (Prefix Tree)MEDIUM
Think: Each node stores a dict mapping a character to the child node, plus an is_end flag meaning "a word finishes here". insert walks the word creating missing children; search and starts_with walk the same path — the only difference is whether the final node must have is_end set.
1
insert: start at the root; for each char use node.children.setdefault(ch, TrieNode()); mark the last node is_end = True.
2
Shared helper _find(prefix): follow the chars, return None as soon as one is missing, otherwise the last node.
3
search: the node exists and is_end is True.
4
starts_with: the node exists.
Time: O(L) per operation, L = word length
Space: O(total characters inserted)
PYTHON — TrieNode with dict children
from typing import Dict, Optional


class TrieNode:
    def __init__(self):
        self.children: Dict[str, "TrieNode"] = {}
        self.is_end = False


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            node = node.children.setdefault(ch, TrieNode())
        node.is_end = True

    def _find(self, prefix: str) -> Optional[TrieNode]:
        node = self.root
        for ch in prefix:
            node = node.children.get(ch)
            if node is None:
                return None
        return node

    def search(self, word: str) -> bool:
        node = self._find(word)
        return node is not None and node.is_end

    def starts_with(self, prefix: str) -> bool:
        return self._find(prefix) is not None


trie = Trie()
trie.insert("apple")
print(trie.search("apple"))    # True
print(trie.search("app"))      # False  ("app" is only a prefix so far)
print(trie.starts_with("app")) # True
trie.insert("app")
print(trie.search("app"))      # True
print(trie.starts_with("b"))   # False
Python tip: dict.setdefault(key, default) returns the existing child or inserts and returns the new one in a single call. Note it builds a TrieNode() every time even when unused — if ch not in node.children: ... avoids that if it matters.
02Design Add and Search Words Data StructureMEDIUM
Think: Same trie for add_word. search must also handle '.', which matches any letter. A normal character has one path to follow; a dot means "try every child". That branching is a DFS: dfs(node, i) answers "can word[i:] be matched starting from node?".
1
add_word: standard trie insert.
2
dfs(node, i): if i == len(word), return node.is_end.
3
If word[i] == '.', return True if dfs(child, i + 1) succeeds for any child.
4
Otherwise follow the single child for word[i] (return False if it is missing).
Time: add O(L); search O(L) without dots, up to O(26^L) worst case with dots
Space: O(total characters) + O(L) recursion
PYTHON — Trie + DFS for '.' wildcard
from typing import Dict


class TrieNode:
    def __init__(self):
        self.children: Dict[str, "TrieNode"] = {}
        self.is_end = False


class WordDictionary:
    def __init__(self):
        self.root = TrieNode()

    def add_word(self, word: str) -> None:
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True

    def search(self, word: str) -> bool:
        def dfs(node: TrieNode, i: int) -> bool:
            if i == len(word):
                return node.is_end
            ch = word[i]
            if ch == ".":
                # wildcard: any child may continue the match
                return any(dfs(child, i + 1) for child in node.children.values())
            child = node.children.get(ch)
            return child is not None and dfs(child, i + 1)

        return dfs(self.root, 0)


wd = WordDictionary()
for w in ["bad", "dad", "mad"]:
    wd.add_word(w)
print(wd.search("pad"))  # False
print(wd.search("bad"))  # True
print(wd.search(".ad"))  # True
print(wd.search("b.."))  # True
print(wd.search("b."))   # False  (too short — no word ends after 2 chars)
print(wd.search("..."))  # True
Python tip: any() with a generator short-circuits: it stops exploring children the moment one branch returns True.
03Word Search IIHARD
Think: Running Word Search once per word repeats the same grid walks. Instead put all words in a trie and backtrack over the grid once: from each cell, only step to a neighbour if that letter is a child of the current trie node. Store the full word on its end node so you can record it when reached. Prune aggressively: clear the word after finding it (no duplicates) and delete trie leaves that are exhausted, so later searches skip dead branches.
1
Build a trie of the words; set node.word = word on each end node.
2
For each cell, call backtrack(r, c, root) if board[r][c] is a child of the root.
3
In backtrack: move to the child node; if it holds a word, add it to the result and set node.word = None.
4
Mark the cell '#' (visited), recurse into the 4 neighbours whose letter is a child, then restore the letter.
5
Pruning: if the child has no children left after the recursion, delete it from its parent.
Time: O(rows × cols × 4 × 3^(L−1)), L = longest word
Space: O(total characters in words)
PYTHON — Trie + grid backtracking with pruning
from typing import Dict, List, Optional


class TrieNode:
    def __init__(self):
        self.children: Dict[str, "TrieNode"] = {}
        self.word: Optional[str] = None     # full word stored at its end node


def find_words(board: List[List[str]], words: List[str]) -> List[str]:
    root = TrieNode()
    for w in words:
        node = root
        for ch in w:
            node = node.children.setdefault(ch, TrieNode())
        node.word = w

    rows, cols = len(board), len(board[0])
    found = []

    def backtrack(r: int, c: int, parent: TrieNode) -> None:
        ch = board[r][c]
        node = parent.children[ch]
        if node.word is not None:
            found.append(node.word)
            node.word = None                 # never report the same word twice

        board[r][c] = "#"                    # mark visited
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and board[nr][nc] in node.children:
                backtrack(nr, nc, node)
        board[r][c] = ch                     # restore (backtrack)

        if not node.children and node.word is None:
            del parent.children[ch]          # prune exhausted branch

    for r in range(rows):
        for c in range(cols):
            if board[r][c] in root.children:
                backtrack(r, c, root)
    return found


board = [
    ["o", "a", "a", "n"],
    ["e", "t", "a", "e"],
    ["i", "h", "k", "r"],
    ["i", "f", "l", "v"],
]
print(sorted(find_words(board, ["oath", "pea", "eat", "rain"])))  # ['eat', 'oath']
print(find_words([["a", "b"], ["c", "d"]], ["abcb"]))              # []
print(sorted(find_words([["a", "b"], ["c", "d"]], ["ab", "abdc", "ac", "x"])))  # ['ab', 'abdc', 'ac']
Python tip: The '#' marker is never a trie key, so the check board[nr][nc] in node.children rejects visited cells and non-matching letters in one test.
