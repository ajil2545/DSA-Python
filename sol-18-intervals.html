SOLUTIONS 18

Interval Solutions

Sort, scan, compare with the previous block — and a heap or two pointers when you need to count overlaps.

01Merge IntervalsMEDIUM
Think: After sorting by start, an interval can only overlap the block directly before it. Keep the output's last element as the block under construction and either stretch it or start a new one.
1
Sort by start (sorted(intervals, key=lambda x: x[0])).
2
If start <= merged[-1][1], set the block's end to the max of both ends.
3
Otherwise append a fresh [start, end] (a new list, so the input is never mutated).
Time: O(n log n)
Space: O(n) for the output
SOLUTION
from typing import List


def merge(intervals: List[List[int]]) -> List[List[int]]:
    merged: List[List[int]] = []
    for start, end in sorted(intervals, key=lambda x: x[0]):
        if merged and start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged


print(merge([[1, 3], [2, 6], [8, 10], [15, 18]]))  # [[1, 6], [8, 10], [15, 18]]
print(merge([[1, 4], [4, 5]]))                     # [[1, 5]]  (touching merges)
print(merge([[4, 7], [1, 4]]))                     # [[1, 7]]  (unsorted input)
02Insert IntervalMEDIUM
Think: The list is already sorted and disjoint, so no sort is needed. Everything splits into three runs: intervals entirely left of the new one, intervals overlapping it (absorb them), and intervals entirely to its right.
1
Copy intervals whose end < new.start.
2
While interval.start <= new.end, widen new to cover it.
3
Append the widened interval, then extend with the remaining slice.
Time: O(n)
Space: O(n) for the output
SOLUTION — Three Phases
from typing import List


def insert(intervals: List[List[int]], new_interval: List[int]) -> List[List[int]]:
    result: List[List[int]] = []
    start, end = new_interval
    i, n = 0, len(intervals)
    while i < n and intervals[i][1] < start:          # left of new
        result.append(intervals[i])
        i += 1
    while i < n and intervals[i][0] <= end:           # overlapping: merge into new
        start = min(start, intervals[i][0])
        end = max(end, intervals[i][1])
        i += 1
    result.append([start, end])
    result.extend(intervals[i:])                      # right of new
    return result


print(insert([[1, 3], [6, 9]], [2, 5]))                          # [[1, 5], [6, 9]]
print(insert([[1, 2], [3, 5], [6, 7], [8, 10], [12, 16]], [4, 8]))  # [[1, 2], [3, 10], [12, 16]]
print(insert([], [5, 7]))                                        # [[5, 7]]
03Non-overlapping IntervalsMEDIUM
Think: Minimum removals = n - (maximum number of non-overlapping intervals you can keep). Keeping the maximum is activity selection: sort by end and greedily keep each interval that starts at or after the last kept end. Ending earliest leaves the most room for the rest (exchange argument). Touching intervals like [1,2] and [2,3] do not overlap here.
1
Sort by end time.
2
Track prev_end of the last kept interval (start at -inf).
3
If start >= prev_end, keep it and update prev_end; otherwise count a removal.
Time: O(n log n)
Space: O(n) for the sorted copy
SOLUTION — Greedy by Earliest End
from typing import List


def erase_overlap_intervals(intervals: List[List[int]]) -> int:
    removed = 0
    prev_end = float('-inf')
    for start, end in sorted(intervals, key=lambda x: x[1]):
        if start >= prev_end:      # fits after the last kept interval
            prev_end = end
        else:                      # overlaps: drop it (it ends later than the kept one)
            removed += 1
    return removed


print(erase_overlap_intervals([[1, 2], [2, 3], [3, 4], [1, 3]]))  # 1
print(erase_overlap_intervals([[1, 2], [1, 2], [1, 2]]))          # 2
print(erase_overlap_intervals([[1, 2], [2, 3]]))                  # 0
04Meeting RoomsEASY
Think: One person can attend all meetings iff no two overlap. After sorting by start, it's enough to compare each meeting with the previous one: if the previous ends after this one starts, there's a clash. Meetings are half-open, so ending at 10 and starting at 10 is fine.
1
Sort by start.
2
Pair neighbours with zip(intervals, intervals[1:]).
3
Return all(prev_end <= cur_start).
Time: O(n log n)
Space: O(n) for the sorted copy
SOLUTION
from typing import List


def can_attend_meetings(intervals: List[List[int]]) -> bool:
    intervals = sorted(intervals, key=lambda x: x[0])
    return all(prev[1] <= cur[0] for prev, cur in zip(intervals, intervals[1:]))


print(can_attend_meetings([[0, 30], [5, 10], [15, 20]]))  # False
print(can_attend_meetings([[7, 10], [2, 4]]))             # True
print(can_attend_meetings([[1, 5], [5, 8]]))              # True (back-to-back)
05Meeting Rooms IIMEDIUM
Think: Rooms needed = maximum number of meetings running at the same moment. Process meetings by start time and keep a min-heap of the end times of rooms currently in use. If the room that frees up earliest is free by this start, reuse it; otherwise open a new room.
1
Sort meetings by start.
2
If ends[0] <= start, heapreplace that end with the new end (room reused).
3
Else heappush the new end (new room).
4
Answer: len(ends). The two-pointer version on separately sorted starts/ends gives the same count.
Time: O(n log n)
Space: O(n)
SOLUTION — Min-Heap of End Times
import heapq
from typing import List


def min_meeting_rooms(intervals: List[List[int]]) -> int:
    ends: List[int] = []
    for start, end in sorted(intervals, key=lambda x: x[0]):
        if ends and ends[0] <= start:
            heapq.heapreplace(ends, end)    # reuse the room that freed up earliest
        else:
            heapq.heappush(ends, end)       # all rooms busy: open a new one
    return len(ends)


print(min_meeting_rooms([[0, 30], [5, 10], [15, 20]]))          # 2
print(min_meeting_rooms([[7, 10], [2, 4]]))                     # 1
print(min_meeting_rooms([[1, 5], [2, 6], [4, 8], [5, 9]]))      # 3
ALTERNATIVE — Sorted Starts and Ends (Two Pointers)
from typing import List


def min_meeting_rooms_sweep(intervals: List[List[int]]) -> int:
    starts = sorted(s for s, _ in intervals)
    ends = sorted(e for _, e in intervals)
    rooms = j = 0
    for s in starts:
        if s < ends[j]:       # nothing has finished yet → need another room
            rooms += 1
        else:                 # a meeting ended: its room is reused
            j += 1
    return rooms


print(min_meeting_rooms_sweep([[0, 30], [5, 10], [15, 20]]))      # 2
print(min_meeting_rooms_sweep([[1, 5], [2, 6], [4, 8], [5, 9]]))  # 3
06Interval List IntersectionsMEDIUM
Think: Both lists are sorted and internally disjoint, so walk them with two pointers like merging sorted arrays. The candidate intersection of the current pair is [max(starts), min(ends)]. Then advance whichever interval ends first — it cannot intersect anything further in the other list.
1
Pointers i into first and j into second.
2
Compute lo = max(a_start, b_start), hi = min(a_end, b_end); if lo <= hi, record [lo, hi].
3
Advance the pointer whose interval has the smaller end.
4
Stop when either list runs out.
Time: O(m + n)
Space: O(1) extra (output aside)
SOLUTION — Two Pointers
from typing import List


def interval_intersection(first: List[List[int]], second: List[List[int]]) -> List[List[int]]:
    i = j = 0
    result: List[List[int]] = []
    while i < len(first) and j < len(second):
        lo = max(first[i][0], second[j][0])
        hi = min(first[i][1], second[j][1])
        if lo <= hi:
            result.append([lo, hi])
        if first[i][1] < second[j][1]:   # the one that ends first is done
            i += 1
        else:
            j += 1
    return result


a = [[0, 2], [5, 10], [13, 23], [24, 25]]
b = [[1, 5], [8, 12], [15, 24], [25, 26]]
print(interval_intersection(a, b))  # [[1, 2], [5, 5], [8, 10], [15, 23], [24, 24], [25, 25]]
print(interval_intersection([[1, 3], [5, 9]], []))  # []
