01Two Sum II — Input Array Is SortedMEDIUM
Think: The list is sorted, so the sum of the two ends tells us which way to go: too small → the left value is useless, move it right; too big → the right value is useless, move it left. LeetCode wants 1-based indices.
1
Put left = 0, right = len(numbers) - 1.
2
Compare numbers[left] + numbers[right] with the target.
3
Equal → return [left + 1, right + 1]; smaller → left += 1; bigger → right -= 1.
Time: O(n)
Space: O(1)
SOLUTION — Opposite Ends
from typing import List

def two_sum_ii(numbers: List[int], target: int) -> List[int]:
    left, right = 0, len(numbers) - 1
    while left < right:
        total = numbers[left] + numbers[right]
        if total == target:
            return [left + 1, right + 1]     # 1-indexed
        if total < target:
            left += 1
        else:
            right -= 1
    return []                                # problem guarantees an answer

print(two_sum_ii([2, 7, 11, 15], 9))  # [1, 2]
print(two_sum_ii([2, 3, 4], 6))       # [1, 3]
print(two_sum_ii([-1, 0], -1))        # [1, 2]
023SumMEDIUM
Think: Sort, then fix one number nums[i] and solve Two Sum II on the rest for target -nums[i]. Duplicates are the hard part: skip a fixed value equal to the previous one, and after a hit skip equal neighbours of lo. Sorting also lets us stop early once nums[i] > 0.
1
Sort a copy: nums = sorted(nums).
2
For each i: break if nums[i] > 0; skip if i > 0 and nums[i] == nums[i - 1].
3
Two pointers lo = i + 1, hi = n - 1; move by comparing the triple sum with 0.
4
On a hit, record it, move both pointers, and skip duplicate lo values.
Time: O(n²)
Space: O(n) for the sorted copy (output not counted)
SOLUTION — Sort + Two Pointers
from typing import List

def three_sum(nums: List[int]) -> List[List[int]]:
    nums = sorted(nums)
    n = len(nums)
    result = []
    for i in range(n - 2):
        if nums[i] > 0:
            break                            # smallest is positive → no zero sum
        if i > 0 and nums[i] == nums[i - 1]:
            continue                         # same fixed value → same triples
        lo, hi = i + 1, n - 1
        while lo < hi:
            total = nums[i] + nums[lo] + nums[hi]
            if total < 0:
                lo += 1
            elif total > 0:
                hi -= 1
            else:
                result.append([nums[i], nums[lo], nums[hi]])
                lo += 1
                hi -= 1
                while lo < hi and nums[lo] == nums[lo - 1]:
                    lo += 1                  # skip duplicate second numbers
    return result

print(three_sum([-1, 0, 1, 2, -1, -4]))  # [[-1, -1, 2], [-1, 0, 1]]
print(three_sum([0, 1, 1]))              # []
print(three_sum([0, 0, 0]))              # [[0, 0, 0]]
03Container With Most WaterMEDIUM
Think: Start with the widest container (both ends). The water level is limited by the shorter wall, so moving the taller wall can only lose width without gaining height. Move the shorter wall and keep the best area seen.
1
left, right = 0, len(height) - 1, best = 0.
2
Area = min(height[left], height[right]) * (right - left); update best.
3
Move whichever pointer has the shorter wall; stop when they meet.
Time: O(n)
Space: O(1)
SOLUTION — Greedy Two Pointers
from typing import List

def max_area(height: List[int]) -> int:
    left, right = 0, len(height) - 1
    best = 0
    while left < right:
        h = min(height[left], height[right])
        best = max(best, h * (right - left))
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    return best

print(max_area([1, 8, 6, 2, 5, 4, 8, 3, 7]))  # 49
print(max_area([1, 1]))                       # 1
print(max_area([4, 3, 2, 1, 4]))              # 16
04Longest Substring Without Repeating CharactersMEDIUM
Think: Variable window. Instead of shrinking one char at a time with a set, remember the last index of every char in a dict. When ch repeats inside the window, jump left straight past its previous position. Guard with >= left so an old occurrence outside the window is ignored.
1
last_seen = {}, left = best = 0.
2
For each right, ch: if ch was seen at index ≥ left, set left = last_seen[ch] + 1.
3
Store last_seen[ch] = right and update best = max(best, right - left + 1).
Time: O(n)
Space: O(min(n, alphabet))
SOLUTION — Sliding Window with dict of last index
def length_of_longest_substring(s: str) -> int:
    last_seen = {}
    left = best = 0
    for right, ch in enumerate(s):
        if last_seen.get(ch, -1) >= left:
            left = last_seen[ch] + 1     # jump past the previous copy
        last_seen[ch] = right
        best = max(best, right - left + 1)
    return best

print(length_of_longest_substring("abcabcbb"))  # 3  ("abc")
print(length_of_longest_substring("bbbbb"))     # 1  ("b")
print(length_of_longest_substring("pwwkew"))    # 3  ("wke")
print(length_of_longest_substring(""))          # 0
print(length_of_longest_substring("abba"))      # 2  (guard needed here)
05Minimum Window SubstringHARD
Think: Expand right until the window contains all of t; then shrink left as far as possible while it stays valid, recording the smallest window. A Counter stores how many of each char the window still owes (negative = surplus) and one integer missing makes “is it valid?” O(1).
1
need = Counter(t), missing = len(t).
2
Expand: if need[ch] > 0 it was a required char → missing -= 1; always need[ch] -= 1.
3
While missing == 0: record the window, give back s[left] (need[...] += 1); if that makes it positive, missing += 1; left += 1.
4
Return the best slice, or "" if the window was never valid.
Time: O(|s| + |t|)
Space: O(alphabet)
SOLUTION — Variable Window + Counter
from collections import Counter

def min_window(s: str, t: str) -> str:
    if not s or not t:
        return ""
    need = Counter(t)
    missing = len(t)
    left = 0
    best_start, best_len = 0, float('inf')
    for right, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        while missing == 0:
            if right - left + 1 < best_len:
                best_start, best_len = left, right - left + 1
            need[s[left]] += 1
            if need[s[left]] > 0:
                missing += 1
            left += 1
    if best_len == float('inf'):
        return ""
    return s[best_start:best_start + best_len]

print(repr(min_window("ADOBECODEBANC", "ABC")))  # 'BANC'
print(repr(min_window("a", "a")))                # 'a'
print(repr(min_window("a", "aa")))               # ''  (need two a's)
06Max Sum Subarray of Size KEASY
Think: Fixed window. Sum the first k numbers once; then each slide adds the number entering on the right and subtracts the one leaving on the left. No need to re-sum — O(1) per step.
1
window = sum(nums[:k]), best = window.
2
For right in range(k, len(nums)): window += nums[right] - nums[right - k].
3
Track best = max(best, window).
Time: O(n)
Space: O(1)
SOLUTION — Fixed Sliding Window
from typing import List

def max_sum_subarray(nums: List[int], k: int) -> int:
    if k > len(nums):
        raise ValueError("k is larger than the list")
    window = sum(nums[:k])
    best = window
    for right in range(k, len(nums)):
        window += nums[right] - nums[right - k]
        best = max(best, window)
    return best

print(max_sum_subarray([2, 1, 5, 1, 3, 2], 3))  # 9  ([5, 1, 3])
print(max_sum_subarray([2, 3, 4, 1, 5], 2))     # 7  ([3, 4])
print(max_sum_subarray([-1, -2, -3], 1))        # -1
BONUS — Same idea with itertools (also O(n))
from itertools import accumulate

def max_sum_subarray_prefix(nums, k):
    prefix = [0] + list(accumulate(nums))        # prefix[i] = sum(nums[:i])
    return max(prefix[i + k] - prefix[i] for i in range(len(nums) - k + 1))

print(max_sum_subarray_prefix([2, 1, 5, 1, 3, 2], 3))  # 9
