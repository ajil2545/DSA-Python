Trees & BST

Hierarchical data. Trees are everywhere — file systems, HTML DOM, databases, compilers. Master traversals and BST operations.

BST SEARCH
O(log n)*
BST INSERT
O(log n)*
BST DELETE
O(log n)*
TRAVERSAL
O(n)
Note: *BST operations are really O(h), where h is the tree height. That is O(log n) only when the tree is balanced; inserting already-sorted values builds a "stick" tree with h = n, so every operation degrades to O(n). Self-balancing trees (AVL, red-black) guarantee O(log n).
CONCEPT 01

Binary Tree Node

BINARY TREE STRUCTURE
           [4]          ← root
          /   \
       [2]     [6]      ← children
       / \     / \
     [1] [3] [5] [7]   ← leaves

  Every node has: val, left child, right child
PYTHON — Tree Node
from typing import Optional

class TreeNode:
    def __init__(self, val: int = 0,
                 left: "Optional[TreeNode]" = None,
                 right: "Optional[TreeNode]" = None) -> None:
        self.val = val
        self.left = left
        self.right = right

    def __repr__(self) -> str:       # nicer print() output while debugging
        return "TreeNode({})".format(self.val)

# Build the tree above manually:
root = TreeNode(4)
root.left  = TreeNode(2)
root.right = TreeNode(6)
root.left.left   = TreeNode(1)
root.left.right  = TreeNode(3)
root.right.left  = TreeNode(5)
root.right.right = TreeNode(7)

# ...or in one expression using the keyword defaults:
root = TreeNode(4, TreeNode(2, TreeNode(1), TreeNode(3)),
                   TreeNode(6, TreeNode(5), TreeNode(7)))
print(root, root.left, root.right.right)  # TreeNode(4) TreeNode(2) TreeNode(7)
TECHNIQUE 01

Tree Traversals (DFS)

Three DFS orders differ only in when you visit the root: before children (preorder), between them (inorder), or after (postorder). Inorder on a BST gives sorted output!

PYTHON — All Three DFS Traversals
from typing import List, Optional

# Inorder: Left → Root → Right  (gives sorted for BST)
def inorder(node: Optional[TreeNode], result: Optional[List[int]] = None) -> List[int]:
    if result is None:          # never use result=[] as a default (see note)
        result = []
    if node:
        inorder(node.left, result)
        result.append(node.val)  # ← visit in MIDDLE
        inorder(node.right, result)
    return result

# Preorder: Root → Left → Right  (useful for copying trees)
def preorder(node: Optional[TreeNode]) -> List[int]:
    if not node:
        return []
    return [node.val] + preorder(node.left) + preorder(node.right)  # ← visit FIRST

# Postorder: Left → Right → Root  (useful for deleting trees)
# Generator version: yield values lazily, no result list to pass around
def postorder(node: Optional[TreeNode]):
    if node:
        yield from postorder(node.left)
        yield from postorder(node.right)
        yield node.val          # ← visit LAST

# On our tree [4,2,6,1,3,5,7]:
print(inorder(root))          # → [1, 2, 3, 4, 5, 6, 7]  ← sorted!
print(preorder(root))         # → [4, 2, 1, 3, 6, 5, 7]
print(list(postorder(root)))   # → [1, 3, 2, 5, 7, 6, 4]
Mutable default trap: def inorder(node, result=[]) creates the list once, when the function is defined — every later call keeps appending to the same list. Use result=None and create the list inside, as above.
TECHNIQUE 02

Iterative Traversals & the Recursion Limit

CPython caps recursion depth at about 1000 frames (sys.getrecursionlimit()). A balanced tree of a million nodes is only ~20 deep, but a degenerate (linked-list shaped) tree of 10,000 nodes raises RecursionError. You can raise the cap with sys.setrecursionlimit(10**6), but very deep recursion can still crash the interpreter — the robust fix is an explicit stack.

PYTHON — Iterative Inorder & Preorder
import sys
from typing import List, Optional

def inorder_iterative(root: Optional[TreeNode]) -> List[int]:
    result, stack = [], []
    node = root
    while node or stack:
        while node:              # go as far left as possible
            stack.append(node)
            node = node.left
        node = stack.pop()       # visit
        result.append(node.val)
        node = node.right        # then the right subtree
    return result

def preorder_iterative(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    result, stack = [], [root]
    while stack:
        node = stack.pop()
        result.append(node.val)
        if node.right:            # push right first so left is processed first
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return result

print(inorder_iterative(root))   # → [1, 2, 3, 4, 5, 6, 7]
print(preorder_iterative(root))  # → [4, 2, 1, 3, 6, 5, 7]

# A 5000-deep "stick" tree: recursion would hit the default limit
deep = TreeNode(0)
cur = deep
for i in range(1, 5000):
    cur.right = TreeNode(i)
    cur = cur.right
print(len(inorder_iterative(deep)))  # → 5000, no RecursionError
print(sys.getrecursionlimit())          # → 1000 (typical default)
TECHNIQUE 03

BST Insert & Search

A Binary Search Tree maintains the invariant: left subtree values < node value < right subtree values. Each comparison discards one whole subtree, so a search costs O(h) — O(log n) in a balanced tree, where every step roughly halves the remaining nodes. Equal values go right in the code below.

PYTHON — BST Insert & Search
def insert(root: Optional[TreeNode], val: int) -> TreeNode:
    if not root:
        return TreeNode(val)                 # place here

    if val < root.val:
        root.left = insert(root.left, val)    # go left
    else:
        root.right = insert(root.right, val)  # go right

    return root

def search(root: Optional[TreeNode], target: int) -> bool:
    if not root:
        return False                         # not found
    if root.val == target:
        return True                          # found!

    if target < root.val:
        return search(root.left, target)     # go left
    else:
        return search(root.right, target)    # go right

bst = None
for v in [4, 2, 6, 1, 3, 5, 7]:
    bst = insert(bst, v)
print(search(bst, 5), search(bst, 8))  # → True False
print(inorder(bst))                   # → [1, 2, 3, 4, 5, 6, 7]
TECHNIQUE 04

Tree Height & Diameter

PYTHON — Max Depth of Binary Tree
def max_depth(root: Optional[TreeNode]) -> int:
    if not root:
        return 0  # None node has depth 0

    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)

    # Current node adds 1 to the deeper subtree
    return 1 + max(left_depth, right_depth)

print(max_depth(root))  # → 3 (for our 7-node tree)

The diameter is the number of edges on the longest path between any two nodes. That path bends at some node, where it is height(left) + height(right) long. One postorder pass computes every height and tracks the best bend — O(n). The nonlocal keyword lets the inner function update the outer variable.

PYTHON — Diameter of Binary Tree
def diameter(root: Optional[TreeNode]) -> int:
    best = 0

    def height(node: Optional[TreeNode]) -> int:
        nonlocal best
        if not node:
            return 0
        left, right = height(node.left), height(node.right)
        best = max(best, left + right)   # longest path bending at this node
        return 1 + max(left, right)

    height(root)
    return best

print(diameter(root))  # → 4 (e.g. 1 → 2 → 4 → 6 → 7)
