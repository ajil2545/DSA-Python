01Climbing StairsEASY
Problem: To reach stair n, you can take 1 or 2 steps. How many distinct ways?

Think: To reach step n, you must have come from step n-1 (took 1 step) OR step n-2 (took 2 steps). So ways(n) = ways(n-1) + ways(n-2). That's Fibonacci! Base cases: 1 way to reach step 1, 2 ways to reach step 2.
Time: O(n)
Space: O(1)
SOLUTION
from functools import lru_cache


def climb_stairs(n: int) -> int:
    if n <= 2:
        return n

    prev2, prev1 = 1, 2  # ways to reach step n-2, step n-1

    for _ in range(3, n + 1):
        # ways(n) = ways(n-1) + ways(n-2) — tuple assignment, no temp needed
        prev2, prev1 = prev1, prev1 + prev2

    return prev1


# Top-down version: same recurrence, Python caches it for you
@lru_cache(maxsize=None)
def climb_stairs_memo(n: int) -> int:
    if n <= 2:
        return n
    return climb_stairs_memo(n - 1) + climb_stairs_memo(n - 2)


# n=5: 1,2,3,5,8  → 8 ways
# (only need last 2 values, O(1) space)
print(climb_stairs(5))       # 8
print(climb_stairs_memo(5))  # 8
02House RobberMEDIUM
Problem: Rob houses along a street, but can't rob two adjacent houses. Maximize stolen amount.

Think: At each house you have two choices: rob it (can't have robbed previous) OR skip it (keep previous max). rob(i) = max(nums[i] + rob(i-2), rob(i-1)).
Time: O(n)
Space: O(1)
SOLUTION
from typing import List


def rob(nums: List[int]) -> int:
    prev2 = 0  # max if we stop 2 houses back
    prev1 = 0  # max if we stop 1 house back

    for amount in nums:
        # Rob current: prev2 + amount
        # Skip current: prev1
        prev2, prev1 = prev1, max(prev2 + amount, prev1)

    return prev1  # maximum of all possibilities


# [2,7,9,3,1]:
# house 2: max(0+2, 0)=2
# house 7: max(0+7, 2)=7
# house 9: max(2+9, 7)=11
# house 3: max(7+3, 11)=11
# house 1: max(11+1, 11)=12  → answer: 12
print(rob([2, 7, 9, 3, 1]))  # 12
03Longest Increasing SubsequenceMEDIUM
Problem: Find the length of the longest strictly increasing subsequence (not necessarily contiguous).

Think: dp[i] = length of LIS ending at index i. For each i, look at all j < i where nums[j] < nums[i]. dp[i] = max(dp[j]) + 1. Answer = max of all dp values. (The bonus bisect version below runs in O(n log n).)
Time: O(n²)
Space: O(n)
SOLUTION
from bisect import bisect_left
from typing import List


def length_of_lis(nums: List[int]) -> int:
    if not nums:
        return 0
    # dp[i] = length of longest increasing subsequence ending at i
    dp = [1] * len(nums)  # every element alone = LIS of 1

    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                # nums[i] can extend the sequence ending at j
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)


# Bonus — O(n log n) with bisect: tails[k] = smallest tail of an
# increasing subsequence of length k+1
def length_of_lis_fast(nums: List[int]) -> int:
    tails: List[int] = []
    for x in nums:
        i = bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)   # x extends the longest sequence
        else:
            tails[i] = x      # x is a smaller tail for length i+1
    return len(tails)


# [10,9,2,5,3,7,101,18]:
# dp: [1, 1, 1, 2, 2, 3,  4,  4]
#                         ↑ answer = max(dp) = 4 (e.g. 2,3,7,101 or 2,5,7,18)
print(length_of_lis([10, 9, 2, 5, 3, 7, 101, 18]))       # 4
print(length_of_lis_fast([10, 9, 2, 5, 3, 7, 101, 18]))  # 4
04Edit DistanceMEDIUM
Problem: Minimum operations (insert, delete, replace) to convert word1 to word2.

Think: 2D DP. dp[i][j] = min edits to convert word1[:i] (first i chars) to word2[:j]. If the last chars match: dp[i][j] = dp[i-1][j-1] (free). Otherwise: 1 + min(delete, insert, replace).
Time: O(m·n)
Space: O(m·n)
SOLUTION
def min_distance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)

    # dp[i][j] = min edits for word1[:i] → word2[:j]
    # Build with a comprehension — NOT [[0] * (n+1)] * (m+1), which aliases rows!
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    # Base: dp[0][j] = j (insert j chars), dp[i][0] = i (delete i chars)
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]  # chars match, free!
            else:
                dp[i][j] = 1 + min(
                    dp[i - 1][j],      # delete from word1
                    dp[i][j - 1],      # insert into word1
                    dp[i - 1][j - 1],  # replace
                )

    return dp[m][n]


print(min_distance("horse", "ros"))            # 3
print(min_distance("intention", "execution"))  # 5
05Unique PathsMEDIUM
Problem: Robot starts top-left, reaches bottom-right, can only move right or down. Count unique paths.

Think: dp[r][c] = paths to reach cell (r,c) = paths from above + paths from left. First row and column all equal 1 (only one way to reach them).
Time: O(m·n)
Space: O(m·n)
SOLUTION
from math import factorial


def unique_paths(m: int, n: int) -> int:
    # Fill entire grid with 1s (first row + col are all 1)
    dp = [[1] * n for _ in range(m)]

    # Fill interior: paths to (r,c) = from top + from left
    for r in range(1, m):
        for c in range(1, n):
            dp[r][c] = dp[r - 1][c] + dp[r][c - 1]

    return dp[-1][-1]  # bottom-right corner (negative index!)


print(unique_paths(3, 7))  # 28
# Cross-check with combinatorics: choose which (m-1) of the
# (m-1)+(n-1) moves are "down" → C(8, 2)  (math.comb on 3.8+)
print(factorial(8) // (factorial(2) * factorial(6)))  # 28
06Longest Common SubsequenceMEDIUM
Problem: Given two strings, return the length of their longest common subsequence (characters in order, not necessarily contiguous).

Think: dp[i][j] = LCS length of text1[:i] and text2[:j]. If the last chars match, extend the diagonal: dp[i-1][j-1] + 1. Otherwise drop one char from either string: max(dp[i-1][j], dp[i][j-1]).
Time: O(m·n)
Space: O(m·n)
SOLUTION
def longest_common_subsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    # Row 0 and column 0 stay 0: LCS with an empty string is 0
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1        # match → extend
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])  # skip one char

    return dp[m][n]


print(longest_common_subsequence("abcde", "ace"))  # 3  ("ace")
print(longest_common_subsequence("abc", "def"))    # 0
07Burst BalloonsHARD
Problem: Bursting balloon i earns nums[i-1] * nums[i] * nums[i+1] (its current neighbours; out-of-range neighbours count as 1). Maximize the total coins from bursting all balloons.

Think: Interval DP. Pad the array with 1 on both ends. Instead of choosing which balloon to burst first, choose which balloon k in the open interval (l, r) is burst last: at that moment its neighbours are exactly l and r, so dp[l][r] = max over k of dp[l][k] + vals[l]·vals[k]·vals[r] + dp[k][r]. Fill by increasing interval length.
Time: O(n³)
Space: O(n²)
SOLUTION
from typing import List


def max_coins(nums: List[int]) -> int:
    vals = [1] + nums + [1]       # virtual 1-balloons on both ends
    size = len(vals)
    # dp[l][r] = max coins from bursting everything strictly between l and r
    dp = [[0] * size for _ in range(size)]

    for length in range(2, size):           # distance r - l
        for l in range(size - length):
            r = l + length
            for k in range(l + 1, r):         # k = last balloon burst in (l, r)
                coins = dp[l][k] + vals[l] * vals[k] * vals[r] + dp[k][r]
                dp[l][r] = max(dp[l][r], coins)

    return dp[0][size - 1]


print(max_coins([3, 1, 5, 8]))  # 167
print(max_coins([1, 5]))        # 10
