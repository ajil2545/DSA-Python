01Jump GameMEDIUM
Think: Instead of trying every jump (exponential, or O(n²) DP), track the farthest index reachable so far. Walk left to right: if the current index is beyond that reach, nothing earlier can get you here, so the end is unreachable.
1
Start with reach = 0.
2
For each index i: if i > reach, return False.
3
Otherwise extend reach = max(reach, i + nums[i]); return early once reach covers the last index.
Time: O(n)
Space: O(1)
SOLUTION
from typing import List


def can_jump(nums: List[int]) -> bool:
    reach = 0
    last = len(nums) - 1
    for i, jump in enumerate(nums):
        if i > reach:              # index i can't be reached
            return False
        reach = max(reach, i + jump)
        if reach >= last:          # early exit: end is already covered
            return True
    return True


print(can_jump([2, 3, 1, 1, 4]))  # True
print(can_jump([3, 2, 1, 0, 4]))  # False
print(can_jump([0]))              # True (already at the end)
02Jump Game IIMEDIUM
Think: Think of it as BFS without a queue. All indices reachable with k jumps form a contiguous window [start, cur_end]. While scanning that window, record the farthest index the next jump can reach. When you hit the end of the window you are forced to jump: increment the count and the window becomes [cur_end + 1, farthest].
1
Keep jumps, cur_end (edge of the current level) and farthest.
2
Scan i from 0 to n - 2 (never jump from the last index), updating farthest.
3
When i == cur_end: jumps += 1 and cur_end = farthest.
Time: O(n)
Space: O(1)
SOLUTION — Implicit BFS Levels
from typing import List


def jump(nums: List[int]) -> int:
    jumps = cur_end = farthest = 0
    for i in range(len(nums) - 1):        # stop before the last index
        farthest = max(farthest, i + nums[i])
        if i == cur_end:                  # used up this jump's window
            jumps += 1
            cur_end = farthest
    return jumps


print(jump([2, 3, 1, 1, 4]))  # 2  (0 -> 1 -> 4)
print(jump([2, 3, 0, 1, 4]))  # 2
print(jump([1]))              # 0
03Gas StationMEDIUM
Think: Two facts. (1) If total gas < total cost, no start works. (2) If you start at s and the tank first goes negative at station i, then no station between s and i can be the start either — each of them would arrive at i with even less fuel (they skip the non-negative prefix you had). So jump the candidate start to i + 1 and reset the tank.
1
If sum(gas) < sum(cost), return -1.
2
Scan once with a running tank: tank += gas[i] - cost[i].
3
When the tank drops below 0, set start = i + 1 and tank = 0.
4
Because a solution exists (step 1), the final start is the answer.
Time: O(n)
Space: O(1)
SOLUTION
from typing import List


def can_complete_circuit(gas: List[int], cost: List[int]) -> int:
    if sum(gas) < sum(cost):
        return -1
    start = tank = 0
    for i, (g, c) in enumerate(zip(gas, cost)):
        tank += g - c
        if tank < 0:          # can't reach i + 1 from start (or from anything in between)
            start = i + 1
            tank = 0
    return start


print(can_complete_circuit([1, 2, 3, 4, 5], [3, 4, 5, 1, 2]))  # 3
print(can_complete_circuit([2, 3, 4], [3, 4, 3]))              # -1
04Assign CookiesEASY
Think: Each child i needs a cookie of size ≥ g[i]; each cookie goes to at most one child. Sort both lists. Give the smallest cookie that satisfies the least greedy unsatisfied child. Wasting a big cookie on a small appetite is never better (exchange argument), and a cookie too small for the least greedy child is useless to everyone.
1
Sort greed factors g and cookie sizes s.
2
Walk the cookies smallest to largest with a pointer child into g.
3
If the cookie satisfies g[child], feed that child (child += 1); otherwise discard the cookie.
4
The answer is the final value of child.
Time: O(n log n + m log m)
Space: O(n + m) for the sorted copies
SOLUTION — Sort + Two Pointers
from typing import List


def find_content_children(g: List[int], s: List[int]) -> int:
    g, s = sorted(g), sorted(s)       # sorted() copies: caller's lists stay untouched
    child = 0
    for cookie in s:
        if child < len(g) and cookie >= g[child]:
            child += 1                # this cookie satisfies the least greedy child left
    return child


print(find_content_children([1, 2, 3], [1, 1]))     # 1
print(find_content_children([1, 2], [1, 2, 3]))     # 2
05Task SchedulerMEDIUM
Think: Only the most frequent task really constrains the schedule. If it appears max_freq times, it forms max_freq - 1 full blocks of length n + 1, plus a final row holding every task that ties for max_freq. Other tasks fill the idle slots; if there are more tasks than slots, no idling is needed at all and the answer is len(tasks).
1
Count tasks with collections.Counter.
2
max_freq = highest count; max_count = how many tasks have that count.
3
Answer = max(len(tasks), (max_freq - 1) * (n + 1) + max_count).
4
Alternative: simulate with a max-heap of remaining counts and a cooldown deque (shown second).
Time: O(N) (heap version: O(answer · log 26), idle ticks included)
Space: O(1) — at most 26 task types
SOLUTION — Counting Formula
from collections import Counter
from typing import List


def least_interval(tasks: List[str], n: int) -> int:
    counts = Counter(tasks)
    max_freq = max(counts.values())
    max_count = sum(1 for c in counts.values() if c == max_freq)
    # A _ _ A _ _ A   -> (max_freq - 1) blocks of (n + 1) slots, then the tied tasks
    return max(len(tasks), (max_freq - 1) * (n + 1) + max_count)


print(least_interval(["A", "A", "A", "B", "B", "B"], 2))  # 8   A B _ A B _ A B
print(least_interval(["A", "C", "A", "B", "D", "B"], 1))  # 6   no idle needed
print(least_interval(["A", "A", "A", "B", "B", "B"], 3))  # 10  A B _ _ A B _ _ A B
ALTERNATIVE — Heap Simulation (Greedy: Run the Most Remaining Task)
import heapq
from collections import Counter, deque
from typing import List


def least_interval_heap(tasks: List[str], n: int) -> int:
    heap = [-c for c in Counter(tasks).values()]   # max-heap via negation
    heapq.heapify(heap)
    cooldown = deque()                              # (time it becomes ready, -remaining)
    time = 0
    while heap or cooldown:
        time += 1
        if heap:
            remaining = heapq.heappop(heap) + 1     # run one instance (counts are negative)
            if remaining:
                cooldown.append((time + n, remaining))
        if cooldown and cooldown[0][0] == time:
            heapq.heappush(heap, cooldown.popleft()[1])
    return time


print(least_interval_heap(["A", "A", "A", "B", "B", "B"], 2))  # 8
print(least_interval_heap(["A", "C", "A", "B", "D", "B"], 1))  # 6
06Partition LabelsMEDIUM
Think: A part must contain every occurrence of each letter in it. Precompute each letter's last index. Scan and keep end = the farthest last-occurrence of any letter seen in the current part. When i reaches end, nothing inside reaches further, so cut here — cutting as early as possible maximises the number of parts.
1
Build last = {ch: i for i, ch in enumerate(s)} (later indices overwrite earlier ones).
2
Scan with start and end; set end = max(end, last[ch]).
3
When i == end, record the size end - start + 1 and start the next part at i + 1.
Time: O(n)
Space: O(1) — at most 26 keys
SOLUTION
from typing import List


def partition_labels(s: str) -> List[int]:
    last = {ch: i for i, ch in enumerate(s)}   # last index of every character
    sizes = []
    start = end = 0
    for i, ch in enumerate(s):
        end = max(end, last[ch])               # this part must stretch to here
        if i == end:                           # every letter so far is closed
            sizes.append(end - start + 1)
            start = i + 1
    return sizes


print(partition_labels("ababcbacadefegdehijhklij"))  # [9, 7, 8]
print(partition_labels("eccbbbbdec"))                # [10]
