CONCEPT 01

String Fundamentals in Python

In Python, str is immutable — s[0] = "h" raises a TypeError. Every "change" (upper, replace, slicing, +) creates a new string. This matters for performance when you're building a string in a loop. Strings support everything lists do for reading: indexing, negative indices, slicing, len(), in, and iteration.

PYTHON — Key String Methods
s = "Hello, World!"

# Access characters
print(s[0])     # H
print(s[-1])    # !   (negative index = from the end)
print(len(s))   # 13
# s[0] = "h"    # TypeError: 'str' object does not support item assignment

# Search
print(s.find("World"))    # 7   (-1 if missing; s.index() raises ValueError instead)
print("Hello" in s)       # True  (substring check, O(n·m) worst case)
print(s.count("l"))       # 3

# Transform (all return NEW strings)
print(s.upper())                      # HELLO, WORLD!
print(s.lower())                      # hello, world!
print("  hi  ".strip())               # hi   (remove whitespace from ends)
print(s.replace("World", "Python"))  # Hello, Python!
print(s.split(", "))                 # ['Hello', 'World!']
print("a b  c".split())              # ['a', 'b', 'c']  (no arg = split on any whitespace)
print(s[7:12])                      # World
print(s[::-1])                       # !dlroW ,olleH

# Character tests
print("a1".isalnum(), "abc".isalpha(), "42".isdigit())  # True True True

# Characters ↔ code points
print(ord("a"))               # 97
print(chr(98))                # b
print(ord("c") - ord("a"))    # 2  ← index into a 26-slot count array

# Build strings efficiently
parts = ["a", "b", "c"]
print("".join(parts))       # abc — use this instead of += in loops
print("-".join(parts))      # a-b-c
Performance tip: Avoid result += ch in a loop. Append pieces to a list and call "".join(pieces) once at the end — that's O(n) total vs up to O(n²), because each += may copy the whole string. (CPython sometimes optimises += in place, but don't rely on it in interviews.)
TECHNIQUE 01

Reversing a String

Reversing is a classic first problem. The trick: convert to a list (since strings are immutable), use two-pointer swap, then "".join() it back.

EXAMPLE — Reverse a String (slicing vs two pointers)
# Method 1: Slicing (interview shorthand)
def reverse1(s: str) -> str:
    return s[::-1]            # or "".join(reversed(s))

# Method 2: Two pointers (shows understanding)
def reverse2(s: str) -> str:
    chars = list(s)          # "hello" → ['h', 'e', 'l', 'l', 'o'] (mutable)
    left, right = 0, len(chars) - 1

    while left < right:
        # Swap characters — tuple unpacking, no temp variable
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1

    return "".join(chars)

print(reverse1("hello"))  # olleh
print(reverse2("hello"))  # olleh
TECHNIQUE 02

Palindrome Check

A palindrome reads the same forwards and backwards. Use two pointers — compare characters from both ends moving inward. Skip non-alphanumeric chars for real-world versions.

EXAMPLE — Valid Palindrome
def is_palindrome(s: str) -> bool:
    # Clean: keep only letters and digits, lowercase (list comprehension + str methods)
    clean = [c.lower() for c in s if c.isalnum()]

    left, right = 0, len(clean) - 1

    while left < right:
        if clean[left] != clean[right]:
            return False
        left += 1
        right -= 1

    return True

print(is_palindrome("A man, a plan, a canal: Panama"))  # True
print(is_palindrome("race a car"))                      # False

# Pythonic shortcut (same O(n)): compare the cleaned list with its reverse
clean = [c.lower() for c in "No 'x' in Nixon" if c.isalnum()]
print(clean == clean[::-1])  # True
TECHNIQUE 03

Anagram Detection

Two strings are anagrams if they contain the exact same characters with the same frequencies. Count characters using a dict (or sort both strings and compare). In Python, collections.Counter does the counting for you.

EXAMPLE — Valid Anagram O(n)
from collections import Counter

def is_anagram(s: str, t: str) -> bool:
    if len(s) != len(t):
        return False

    count = {}

    # Count chars in s (increment) — dict.get(key, default) avoids a KeyError
    for c in s:
        count[c] = count.get(c, 0) + 1

    # Subtract chars in t (decrement)
    for c in t:
        if count.get(c, 0) == 0:
            return False  # char missing or overused
        count[c] -= 1

    return True

print(is_anagram("anagram", "nagaram"))  # True
print(is_anagram("rat", "car"))          # False

# Pythonic: Counter builds the frequency dict in one call
print(Counter("anagram"))                         # Counter({'a': 3, 'n': 1, 'g': 1, 'r': 1, 'm': 1})
print(Counter("anagram") == Counter("nagaram"))  # True
print(sorted("rat") == sorted("car"))          # False  (sorting: O(n log n))
TECHNIQUE 04

Sliding Window on Strings

The sliding window from arrays works perfectly on strings too. Use it for problems asking about substrings with certain properties (longest without repeat, contains all chars, etc.)

EXAMPLE — Longest Substring Without Repeating Characters
def length_of_longest_substring(s: str) -> int:
    seen = set()
    left = max_len = 0

    for right, ch in enumerate(s):
        # If duplicate found, shrink window from left
        while ch in seen:          # set membership: O(1) average
            seen.remove(s[left])
            left += 1

        seen.add(ch)
        max_len = max(max_len, right - left + 1)

    return max_len

print(length_of_longest_substring("abcabcbb"))  # 3 ("abc")
print(length_of_longest_substring("pwwkew"))    # 3 ("wke")
