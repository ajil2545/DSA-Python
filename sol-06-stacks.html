01Min StackMEDIUM
Problem: Design a stack that supports push, pop, top, and get_min — all in O(1).

Think: The trick is knowing the minimum AT EACH STATE of the stack. Use a second stack (min_stack) that tracks the current minimum alongside the main stack. When you push, also push the new minimum.
1
Main stack = normal Python list used as a stack.
2
Min stack = at each position, stores the minimum of everything below AND including that position.
3
When pushing x: append min(x, current_min) to min_stack.
4
get_min() just peeks min_stack[-1].
Time: O(1) per op
Space: O(n)
SOLUTION
class MinStack:
    def __init__(self) -> None:
        self.stack = []
        self.min_stack = []  # parallel stack tracking running minimum

    def push(self, val: int) -> None:
        self.stack.append(val)
        # New minimum is the smaller of: val vs current top of min_stack
        current_min = self.min_stack[-1] if self.min_stack else float('inf')
        self.min_stack.append(min(val, current_min))

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()  # pop both in sync

    def top(self) -> int:
        return self.stack[-1]

    def get_min(self) -> int:
        return self.min_stack[-1]

ms = MinStack()
for x in (5, 3, 7, 2):
    ms.push(x)
# stack:     [5, 3, 7, 2]
# min_stack: [5, 3, 3, 2]
print(ms.get_min())  # 2
ms.pop()
print(ms.get_min())  # 3 (instantly, from min_stack top)
print(ms.top())      # 7
02Daily TemperaturesMEDIUM
Problem: For each day, find how many days until a warmer temperature. Return a list of wait days.

Think: Monotonic decreasing stack of indices. When we find a warmer day, pop everything cooler and record the distance. Any index still in the stack at the end never gets a warmer day (answer = 0).
1
Stack holds indices of days we haven't found a warmer day for yet.
2
For each day, while stack top has a COOLER temperature than today → pop and record distance.
3
Push current day's index onto stack.
Time: O(n)
Space: O(n)
SOLUTION
from typing import List

def daily_temperatures(temps: List[int]) -> List[int]:
    result = [0] * len(temps)
    stack = []  # stores indices of "waiting" days

    for i, t in enumerate(temps):
        # Today is warmer than days still waiting in stack?
        while stack and t > temps[stack[-1]]:
            waiting_day = stack.pop()
            result[waiting_day] = i - waiting_day  # days waited
        stack.append(i)  # add today to waiting list

    return result  # remaining in stack stay 0 (never warmer)

print(daily_temperatures([73, 74, 75, 71, 69, 72, 76, 73]))
# [1, 1, 4, 2, 1, 1, 0, 0]
03Largest Rectangle in HistogramHARD
Problem: Find largest rectangle that fits within a histogram.

Think: For each bar, the rectangle it anchors extends left and right as long as bars are taller. Use a monotonic increasing stack — when we hit a shorter bar, pop taller bars and calculate their max rectangles.
1
Stack stores indices of bars in increasing height order.
2
When current bar is shorter than stack top → pop the top, calculate its max rectangle width.
3
Width = current index - new stack top - 1 (how far the popped bar can extend).
4
Add a 0-height sentinel bar at the end to flush the stack. In Python, heights + [0] builds a new list, so the caller's list is never mutated.
Time: O(n)
Space: O(n)
SOLUTION
from typing import List

def largest_rectangle_area(heights: List[int]) -> int:
    stack = [-1]          # -1 as a base sentinel
    bars = heights + [0]  # sentinel to flush stack at end (new list — input untouched)
    max_area = 0

    for i, height in enumerate(bars):
        while stack[-1] != -1 and height < bars[stack[-1]]:
            h = bars[stack.pop()]     # height of popped bar
            w = i - stack[-1] - 1      # width it can span
            max_area = max(max_area, h * w)
        stack.append(i)

    return max_area

print(largest_rectangle_area([2, 1, 5, 6, 2, 3]))  # 10
