Priority Queues

Always have the min (or max) at the top in O(1). Insert and remove in O(log n). Perfect for "top K" problems and streaming data.

O(1)

CONCEPT 01

What is a Heap?

A complete binary tree stored in a list with one rule: every parent is less than or equal to (min-heap) or greater than or equal to (max-heap) its children. The root is always the min or max. It's NOT fully sorted — just partially ordered.

MIN-HEAP AS LIST
  Tree:        1
             /   \
            3     2
           / \   /
          7   5 4

  List:    [1, 3, 2, 7, 5, 4]
  Index:    0  1  2  3  4  5

  Parent of index i  = (i - 1) // 2
  Left child of i    = 2*i + 1
  Right child of i   = 2*i + 2
CONCEPT 02

Min-Heap Implementation

Two operations maintain heap order: bubble up after insert (swap with parent if smaller), and sink down after extract (move the last element to the root, then keep swapping it with its smaller child). In real Python code you would use heapq (below) — but building it once by hand is how you understand it.

PYTHON — MinHeap (from scratch)
from typing import List

class MinHeap:
    def __init__(self) -> None:
        self.heap: List[int] = []

    def __len__(self) -> int:
        return len(self.heap)

    def peek(self) -> int:
        return self.heap[0]  # min is always root

    def insert(self, val: int) -> None:
        self.heap.append(val)
        self._bubble_up()    # restore heap property

    def extract_min(self) -> int:
        last = self.heap.pop()  # raises IndexError if empty
        if not self.heap:
            return last         # it was the only element
        smallest = self.heap[0]
        self.heap[0] = last   # move last to root
        self._sink_down()    # restore heap property
        return smallest

    def _bubble_up(self) -> None:
        h = self.heap
        i = len(h) - 1
        while i > 0:
            parent = (i - 1) // 2
            if h[parent] <= h[i]:
                break
            h[parent], h[i] = h[i], h[parent]  # tuple-swap
            i = parent

    def _sink_down(self) -> None:
        h = self.heap
        n = len(h)
        i = 0
        while True:
            smallest = i
            left, right = 2 * i + 1, 2 * i + 2
            if left < n and h[left] < h[smallest]:
                smallest = left
            if right < n and h[right] < h[smallest]:
                smallest = right
            if smallest == i:
                break
            h[i], h[smallest] = h[smallest], h[i]
            i = smallest

mh = MinHeap()
for x in [5, 3, 7, 1, 4, 2]:
    mh.insert(x)
print(mh.heap)                                  # → [1, 3, 2, 5, 4, 7]
print([mh.extract_min() for _ in range(len(mh))])  # → [1, 2, 3, 4, 5, 7]
CONCEPT 03

Python's heapq Module

heapq turns any plain list into a min-heap in place — no class needed. heap[0] is always the smallest. There is no built-in max-heap: negate the values on the way in and on the way out.

PYTHON — heapq Essentials
import heapq

heap = []
heapq.heappush(heap, 5)          # O(log n)
heapq.heappush(heap, 1)
heapq.heappush(heap, 3)
print(heap[0])                   # peek min → 1   (O(1))
print(heapq.heappop(heap))       # pop min  → 1   (O(log n))

nums = [3, 2, 1, 5, 6, 4]
heapq.heapify(nums)               # O(n) build, in place
print(nums[0])                   # → 1

# push then pop in one step (faster than the two calls)
print(heapq.heappushpop(nums, 0))  # → 0  (0 is smaller than everything, so it comes straight back)

# Top-k helpers: O(n log k)
data = [3, 2, 1, 5, 6, 4]
print(heapq.nlargest(2, data))   # → [6, 5]
print(heapq.nsmallest(2, data))  # → [1, 2]
words = ["kiwi", "fig", "banana"]
print(heapq.nsmallest(1, words, key=len))  # → ['fig']

# Max-heap: negate in, negate out
max_heap = []
for x in [3, 8, 1]:
    heapq.heappush(max_heap, -x)
print(-max_heap[0])               # peek max → 8
print(-heapq.heappop(max_heap))   # pop max  → 8
PYTHON — Priority Queue with Tuples
import heapq
import itertools

# Tuples compare element by element: (priority, counter, item).
# The counter breaks ties so Python never has to compare the items
# themselves (dicts / custom objects would raise TypeError).
counter = itertools.count()
pq = []
heapq.heappush(pq, (2, next(counter), {"task": "write"}))
heapq.heappush(pq, (1, next(counter), {"task": "plan"}))
heapq.heappush(pq, (1, next(counter), {"task": "review"}))  # same priority

while pq:
    priority, _, item = heapq.heappop(pq)
    print(priority, item["task"])
# 1 plan
# 1 review   ← FIFO among equal priorities, thanks to the counter
# 2 write
Python note: queue.PriorityQueue also exists, but like queue.Queue it is a locking, thread-safe wrapper around heapq — slower and meant for threads. For algorithms use heapq directly on a list.
TECHNIQUE 01

Kth Largest Element

Classic heap pattern: maintain a min-heap of size k. When it exceeds k, pop the smallest. At the end, the root is the kth largest.

EXAMPLE — Kth Largest: sort vs. MinHeap vs. heapq
import heapq
from typing import List

# Interview shorthand — O(n log n)
def find_kth_largest(nums: List[int], k: int) -> int:
    return sorted(nums, reverse=True)[k - 1]  # kth largest is at index k-1

# With our MinHeap — O(n log k):
def kth_largest_heap(nums: List[int], k: int) -> int:
    heap = MinHeap()
    for n in nums:
        heap.insert(n)
        if len(heap) > k:
            heap.extract_min()  # keep only k largest
    return heap.peek()          # smallest of the k largest = kth largest

# Idiomatic Python with heapq — O(n log k):
def kth_largest_heapq(nums: List[int], k: int) -> int:
    heap = nums[:k]
    heapq.heapify(heap)
    for n in nums[k:]:
        if n > heap[0]:
            heapq.heapreplace(heap, n)  # pop min + push n in one O(log k) step
    return heap[0]
    # one-liner: return heapq.nlargest(k, nums)[-1]

print(find_kth_largest([3, 2, 1, 5, 6, 4], 2))   # → 5
print(kth_largest_heap([3, 2, 1, 5, 6, 4], 2))   # → 5
print(kth_largest_heapq([3, 2, 1, 5, 6, 4], 2))  # → 5
