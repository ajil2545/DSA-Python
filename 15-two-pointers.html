Two Pointers & Sliding Window

Turn O(n²) pair and subarray searches into a single O(n) pass — by moving two indices instead of nesting two loops.

TIME
O(n)
EXTRA SPACE
O(1) – O(k)
REPLACES
O(n²)
Big idea: instead of checking every pair with two nested loops, keep two indices that only ever move forward (or toward each other). Each index crosses the list at most once, so the whole scan is O(n). Works on anything indexable: list, str, tuple.
CONCEPT 01

Why Two Pointers Beat Nested Loops

Brute force for “find a pair with sum target” tries all n·(n-1)/2 pairs. If the list is sorted, one comparison tells us which pairs can never work, so we can throw away a whole row of candidates per step instead of one pair.

BRUTE FORCE vs TWO POINTERS
 brute force:  for i in range(n):          two pointers:  left, right = 0, n - 1
                   for j in range(i+1, n):                 while left < right:
                       check(i, j)                              check(left, right)
                                                                 move ONE pointer
 work:  ~n²/2 checks                         work:  at most n - 1 checks
PYTHON — Brute Force Pair Sum (O(n²))
def pair_sum_brute(nums, target):
    n = len(nums)
    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] + nums[j] == target:
                return i, j
    return None

print(pair_sum_brute([1, 2, 4, 7, 11, 15], 15))  # (2, 4)
PATTERN 01

Opposite Ends — Converging Pointers

Start left at index 0 and right at the last index. Look at both ends, decide which pointer to move inward, repeat until they meet. Classic uses: pair/triplet sums in a sorted list, palindromes, reversing in place, and “container” style area problems.

PAIR SUM IN SORTED LIST — target = 15
 nums = [ 1,  2,  4,  7, 11, 15 ]
          L                    R     1 + 15 = 16 > 15  → too big,   right -= 1
          L                R         1 + 11 = 12 < 15  → too small, left  += 1
              L            R         2 + 11 = 13 < 15  → too small, left  += 1
                  L        R         4 + 11 = 15 ✓     → return (2, 4)
PYTHON — Pair Sum in a Sorted List (O(n), O(1) space)
from typing import List, Optional, Tuple

def pair_sum_sorted(nums: List[int], target: int) -> Optional[Tuple[int, int]]:
    left, right = 0, len(nums) - 1
    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return left, right
        if total < target:
            left += 1      # need a bigger sum → move the small end up
        else:
            right -= 1     # need a smaller sum → move the big end down
    return None

print(pair_sum_sorted([1, 2, 4, 7, 11, 15], 15))  # (2, 4)
print(pair_sum_sorted([1, 2, 3], 100))            # None
Why it is safe: if nums[left] + nums[right] is too small, then nums[left] plus any element left of right is also too small — so left can never be part of an answer and we drop it. Every move discards a whole row of pairs.

Container With Most Water uses the same shape with a different rule: the area between two walls is min(h[L], h[R]) * (R - L). Always move the shorter wall — moving the taller one shrinks the width while the height stays capped by the short wall, so it can never help.

CONTAINER WITH MOST WATER
 height = [1, 8, 6, 2, 5, 4, 8, 3, 7]
              ↑                    ↑        L=1 (8), R=8 (7)
              |~~~~~~~~~~~~~~~~~~~~|        area = min(8, 7) * (8 - 1) = 49  ← best
 shorter wall is R → move R left and keep the running max
PYTHON — Container With Most Water
def max_area(height):
    left, right = 0, len(height) - 1
    best = 0
    while left < right:
        width = right - left
        best = max(best, min(height[left], height[right]) * width)
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    return best

print(max_area([1, 8, 6, 2, 5, 4, 8, 3, 7]))  # 49
PYTHON — Valid Palindrome (opposite ends on a str)
def is_palindrome(s: str) -> bool:
    left, right = 0, len(s) - 1
    while left < right:
        if not s[left].isalnum():
            left += 1
        elif not s[right].isalnum():
            right -= 1
        elif s[left].lower() != s[right].lower():
            return False
        else:
            left, right = left + 1, right - 1
    return True

print(is_palindrome("A man, a plan, a canal: Panama"))  # True
print(is_palindrome("race a car"))                      # False
PATTERN 02

Same Direction — Fast & Slow (Reader / Writer)

Both pointers start at the left and move right. The fast pointer (reader) scans every element; the slow pointer (writer) marks where the next element we want to keep should go. This is how you filter a list in place with O(1) extra space.

REMOVE DUPLICATES FROM SORTED LIST
 nums = [0, 0, 1, 1, 1, 2, 2, 3]
         s  f                       nums[f] == nums[s]  → skip
         s     f                    new value 1         → s += 1, nums[s] = 1
 nums = [0, 1, 1, 1, 1, 2, 2, 3]
            s           f           new value 2         → s += 1, nums[s] = 2
 ...                                result: first s+1 = 4 slots are [0, 1, 2, 3]
PYTHON — Remove Duplicates In Place
def remove_duplicates(nums):
    """Return k; nums[:k] holds the unique values (input must be sorted)."""
    if not nums:
        return 0
    slow = 0                           # last position written
    for fast in range(1, len(nums)):   # reader
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1

nums = [0, 0, 1, 1, 1, 2, 2, 3]
k = remove_duplicates(nums)
print(k, nums[:k])  # 4 [0, 1, 2, 3]
PYTHON — Move Zeroes (keep order of non-zeros)
def move_zeroes(nums):
    write = 0
    for read in range(len(nums)):
        if nums[read] != 0:
            nums[write], nums[read] = nums[read], nums[write]   # tuple swap
            write += 1

nums = [0, 1, 0, 3, 12]
move_zeroes(nums)
print(nums)  # [1, 3, 12, 0, 0]
Python note: “in place” means mutate the list object you were given (nums[i] = ..., nums[:] = ...). Writing nums = [x for x in nums if x] inside the function only rebinds the local name — the caller’s list is unchanged. The idiomatic non-in-place version is simply [x for x in nums if x != 0] + [0] * nums.count(0).

The same fast/slow idea on a linked list (fast moves 2 steps, slow moves 1) finds the middle node and detects cycles (Floyd’s algorithm) — see the Linked Lists lesson.

PYTHON — Fast & Slow on a Linked List (middle node)
class ListNode:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next

def middle_node(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next          # 1 step
        fast = fast.next.next     # 2 steps
    return slow

head = None
for v in reversed([1, 2, 3, 4, 5]):
    head = ListNode(v, head)
print(middle_node(head).val)  # 3
PATTERN 03

Fixed-Size Sliding Window

When the problem says “every contiguous subarray / substring of length k”, keep a window of exactly k items. Sliding one step = add the element entering on the right, remove the one leaving on the left. Each step is O(1) instead of re-summing k items.

MAX SUM OF SIZE k = 3
 nums = [2, 1, 5, 1, 3, 2]
        [2  1  5] 1  3  2     sum = 8
         2 [1  5  1] 3  2     sum = 8 - 2 + 1 = 7
         2  1 [5  1  3] 2     sum = 7 - 1 + 3 = 9   ← max
         2  1  5 [1  3  2]    sum = 9 - 5 + 2 = 6
PYTHON — Max Sum Subarray of Size k (O(n))
def max_sum_k(nums, k):
    window = sum(nums[:k])          # first window
    best = window
    for right in range(k, len(nums)):
        window += nums[right] - nums[right - k]   # add new, drop old
        best = max(best, window)
    return best

print(max_sum_k([2, 1, 5, 1, 3, 2], 3))  # 9
Trap: max(sum(nums[i:i+k]) for i in range(len(nums) - k + 1)) reads nicely but slicing and summing is O(k) per window → O(n·k) total. The running-sum version is O(n).

The window state does not have to be a number. Here it is a Counter of letters — we compare the window’s letter counts with the pattern’s to find every anagram.

PYTHON — Find All Anagrams (fixed window + Counter)
from collections import Counter

def find_anagrams(s: str, p: str):
    k = len(p)
    need = Counter(p)
    window = Counter(s[:k])
    result = [0] if window == need else []
    for right in range(k, len(s)):
        window[s[right]] += 1            # char entering
        left_ch = s[right - k]
        window[left_ch] -= 1             # char leaving
        if window[left_ch] == 0:
            del window[left_ch]          # keep == comparison clean
        if window == need:
            result.append(right - k + 1)
    return result

print(find_anagrams("cbaebabacd", "abc"))  # [0, 6]
PATTERN 04

Variable-Size Sliding Window

For “longest / shortest contiguous piece such that …”, the window grows and shrinks. The loop has three beats: 1. expand by moving right (always), 2. shrink by moving left while the window breaks the rule (or, for “shortest”, while it still satisfies it), 3. record the answer. Both pointers only move forward → O(n).

LONGEST SUBSTRING WITHOUT REPEATS — s = "abcabcbb"
 right=0  [a]bcabcbb        window {a}        best 1
 right=2  [abc]abcbb        window {a,b,c}    best 3
 right=3  a[bca]bcbb        'a' repeated → drop 'a' from the left
 right=4  ab[cab]cbb        'b' repeated → drop 'b'
 ...                        best stays 3 ("abc")
PYTHON — Longest Substring Without Repeating Characters
def length_of_longest_substring(s: str) -> int:
    seen = set()          # chars currently inside the window
    left = best = 0
    for right, ch in enumerate(s):
        while ch in seen:            # window invalid → shrink
            seen.remove(s[left])
            left += 1
        seen.add(ch)                 # expand
        best = max(best, right - left + 1)
    return best

print(length_of_longest_substring("abcabcbb"))  # 3
print(length_of_longest_substring("pwwkew"))    # 3
PYTHON — Shortest Subarray with Sum ≥ target (positive numbers)
def min_sub_array_len(target, nums):
    left = total = 0
    best = float('inf')
    for right, x in enumerate(nums):
        total += x                   # expand
        while total >= target:       # valid → shrink to find the shortest
            best = min(best, right - left + 1)
            total -= nums[left]
            left += 1
    return 0 if best == float('inf') else best

print(min_sub_array_len(7, [2, 3, 1, 2, 4, 3]))  # 2  ([4, 3])

Minimum Window Substring is the boss level: find the shortest part of s that contains every character of t (with multiplicity). Track what is still needed with a Counter and a single missing integer so the validity check is O(1).

PYTHON — Minimum Window Substring (Counter + missing count)
from collections import Counter

def min_window(s: str, t: str) -> str:
    need = Counter(t)        # how many of each char the window still owes
    missing = len(t)         # total chars still owed
    left = 0
    best = (0, float('inf'))         # (start, length)
    for right, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1                # negative = surplus inside window
        while missing == 0:          # valid → shrink from the left
            if right - left + 1 < best[1]:
                best = (left, right - left + 1)
            need[s[left]] += 1
            if need[s[left]] > 0:    # we just gave up a required char
                missing += 1
            left += 1
    start, length = best
    return "" if length == float('inf') else s[start:start + length]

print(min_window("ADOBECODEBANC", "ABC"))  # BANC
Only for monotonic windows: the shrink step assumes that growing the window can only push it one way (e.g. the sum only goes up) and shrinking it can only push it back. Sum-based windows therefore need non-negative numbers. With negatives (e.g. “subarray sum equals k”) use prefix sums + a dict instead — see the Hash Maps lesson.
CONCEPT 02

How to Recognise Each Pattern

Read the problem statement for these clues before writing any code:

CLUE → PATTERN
 sorted input + pair / triplet with a target sum   → opposite ends
 palindrome, reverse in place, "two walls" area    → opposite ends
 "in place", "O(1) extra space", remove / move     → same direction (reader / writer)
 middle of linked list, cycle detection            → fast & slow (1 step vs 2 steps)
 "every subarray / substring of length k"          → fixed window
 "longest / shortest contiguous ... such that"     → variable window
 "contains all chars of t", "at most k distinct"   → variable window + dict / Counter
 subarray sum with negative numbers                → NOT a window: prefix sum + dict
Unsorted pair sum? Sort first (O(n log n)) or use a dict (O(n))
Need original indices after sorting? sort indices: sorted(range(n), key=nums.__getitem__)
k-Sum: fix k-2 outer loops, two pointers inside
Window max/min of size k: monotonic collections.deque
Substring problems: window state = Counter or dict of last index
Merging two sorted lists: one pointer per list
TEMPLATES

Reusable Templates

Memorise the skeletons — almost every problem in this family is one of these with a different condition plugged in. (These are skeletons: the ... parts are where your problem’s logic goes.)

TEMPLATE 1 — Opposite Ends
def opposite_ends(arr):
    left, right = 0, len(arr) - 1
    while left < right:
        if found(arr[left], arr[right]):
            return left, right
        if need_bigger(arr[left], arr[right]):
            left += 1
        else:
            right -= 1
    return None
TEMPLATE 2 — Reader / Writer (in place)
def filter_in_place(arr):
    write = 0
    for read in range(len(arr)):
        if keep(arr[read]):
            arr[write] = arr[read]
            write += 1
    return write            # arr[:write] is the answer
TEMPLATE 3 — Fixed Window of size k
def fixed_window(arr, k):
    state = init(arr[:k])
    best = score(state)
    for right in range(k, len(arr)):
        add(state, arr[right])           # element entering
        remove(state, arr[right - k])    # element leaving
        best = better(best, score(state))
    return best
TEMPLATE 4 — Variable Window (longest valid)
from collections import Counter

def variable_window(arr):
    window = Counter()
    left = best = 0
    for right, x in enumerate(arr):
        window[x] += 1                   # 1. expand
        while is_invalid(window):        # 2. shrink until valid
            window[arr[left]] -= 1
            left += 1
        best = max(best, right - left + 1)   # 3. record
    return best
Shortest-valid variant: swap step 2 to while is_valid(window): and record the answer inside the shrink loop (see min_window above).
