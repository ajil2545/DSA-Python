CONCEPT 01

How a Hash Map Works

A hash map stores key → value pairs. Under the hood, it takes your key, runs it through a hash function (Python's built-in hash()), reduces that number to a slot index in an internal array (roughly hash(key) % table_size), and stores the entry in that slot. This is why lookup is O(1) — it's just array access. Python's dict is a hash map.

HASH MAP INTERNALS
  (table of 8 slots — index = hash(key) % 8; numbers are illustrative)

  key: "name"  →  hash("name") % 8 = 3  →  bucket[3] = "Alice"
  key: "age"   →  hash("age")  % 8 = 7  →  bucket[7] = 25
  key: "city"  →  hash("city") % 8 = 1  →  bucket[1] = "NYC"

  d["name"] → hash("name") % 8 = 3 → bucket[3] → "Alice"  ✓  O(1)
PYTHON — dict API
# dict — keys must be HASHABLE (str, int, float, tuple, frozenset, ...)
person = {}                         # or dict()

person["name"] = "Alice"
person["age"] = 30
person[(1, 2)] = "tuple key!"       # tuples are hashable → valid keys
# person[[1, 2]] = "x"              # TypeError: unhashable type: 'list'

print(person["name"])               # Alice
print(person.get("zip"))            # None   (missing key, no KeyError)
print(person.get("zip", "n/a"))     # n/a    (default value)
print("age" in person)              # True
del person["age"]                   # removes entry (KeyError if missing)
print(person.pop("missing", None))  # None   — safe delete with a default
print(len(person))                  # 2

# Iteration — dicts remember insertion order (guaranteed since Python 3.7)
for key, val in person.items():
    print(key, val)                 # name Alice  /  (1, 2) tuple key!

print(list(person.keys()))          # ['name', (1, 2)]

# Build a dict in one line with a dict comprehension
squares = {x: x * x for x in range(4)}
print(squares)                      # {0: 0, 1: 1, 2: 4, 3: 9}
Hashability: a key's hash must never change, so only immutable values can be keys. list, dict and set are mutable → unhashable. Need a list as a key? Convert it: tuple(lst). This is exactly the trick behind Group Anagrams: sorted(word) returns an unhashable list, so use tuple(sorted(word)) (or "".join(sorted(word))) as the key.
CONCEPT 02

Hash Set

A set stores unique values with O(1) lookup. Use it when you only care about existence, not about storing a value alongside the key. Set elements follow the same hashability rule as dict keys.

PYTHON — set API
seen = set()                        # NOT {} — that's an empty dict!

seen.add(1)
seen.add(2)
seen.add(2)                         # duplicate — ignored!
seen.add(3)

print(2 in seen)                    # True
print(len(seen))                    # 3  (not 4)
seen.discard(2)                     # remove; no error if missing (.remove() raises KeyError)

# Create from a list (instant deduplication)
unique = set([1, 2, 2, 3, 3])       # {1, 2, 3}
arr = sorted(unique)                # back to a list: [1, 2, 3]
print(unique, arr)                  # {1, 2, 3} [1, 2, 3]

# Set algebra — handy for "common elements" style problems
a, b = {1, 2, 3}, {2, 3, 4}
print(a & b)                       # {2, 3}         intersection
print(a | b)                       # {1, 2, 3, 4}   union
print(a - b)                       # {1}            difference

# A set of sets needs frozenset (immutable → hashable)
groups = {frozenset({1, 2}), frozenset({2, 1})}
print(len(groups))                  # 1
CONCEPT 03

defaultdict & Counter

The collections module gives you two dict subclasses that remove almost all boilerplate from hash map problems. defaultdict creates a default value the first time a missing key is accessed; Counter is a dict specialised for counting, with most_common() built in.

PYTHON — collections power tools
from collections import defaultdict, Counter

# defaultdict — missing keys get a default automatically
graph = defaultdict(list)
graph["a"].append("b")              # no KeyError: "a" → [] is created first
graph["a"].append("c")
print(dict(graph))                  # {'a': ['b', 'c']}

counts = defaultdict(int)            # int() == 0
for ch in "banana":
    counts[ch] += 1
print(dict(counts))                 # {'b': 1, 'a': 3, 'n': 2}

# Counter — a dict built for counting
c = Counter("banana")
print(c)                            # Counter({'a': 3, 'n': 2, 'b': 1})
print(c["a"], c["z"])                # 3 0   (missing → 0, no KeyError)
print(c.most_common(2))             # [('a', 3), ('n', 2)]
print(Counter("listen") == Counter("silent"))  # True — one-line anagram check!
defaultdict gotcha: merely reading d[missing] inserts the key. If you only want to peek, use d.get(key, 0) or key in d.
TECHNIQUE 01

Frequency Count

Counting how often each element appears is one of the most common hash map patterns. Build a frequency map in O(n), then query any count in O(1).

EXAMPLE — Top K Frequent Elements
from collections import Counter
from typing import List

def top_k_frequent(nums: List[int], k: int) -> List[int]:
    # Step 1: Count frequencies — O(n)
    freq = {}
    for n in nums:
        freq[n] = freq.get(n, 0) + 1

    # Step 2: Sort keys by their frequency (descending), take top k
    ordered = sorted(freq, key=freq.get, reverse=True)
    return ordered[:k]

print(top_k_frequent([1, 1, 1, 2, 2, 3], 2))   # [1, 2]

# Pythonic version — Counter does steps 1 + 2 for you
print([n for n, _ in Counter([1, 1, 1, 2, 2, 3]).most_common(2)])  # [1, 2]
TECHNIQUE 02

Two Sum Pattern

Instead of checking every pair O(n²), use a hash map: store what you've seen, and for each new element check if its complement already exists. Classic O(n) trick.

EXAMPLE — Two Sum O(n)
from typing import List

def two_sum(nums: List[int], target: int) -> List[int]:
    seen = {}                            # value → index

    for i, num in enumerate(nums):
        complement = target - num

        if complement in seen:
            return [seen[complement], i]  # found!

        seen[num] = i                    # store current number

    return []                            # no pair found

print(two_sum([2, 7, 11, 15], 9))      # [0, 1]  (2+7=9)
