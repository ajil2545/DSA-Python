Bit Manipulation

Work directly on the 0s and 1s — O(1) tricks, XOR magic, and subsets packed into a single Python int.

SINGLE BIT OP
O(1)
COUNT SET BITS
O(set bits)
ALL SUBSETS
O(2ⁿ · n)
Why learn this: bit tricks turn some problems into one-liners (find the unique number, power of two), give O(1)-space solutions where a set would cost O(n), and let you store a whole subset of ≤ 20-ish items in a single int — the foundation of bitmask DP.
CONCEPT 01

Binary Representation in Python

Every integer is a sum of powers of two. Bit i (counting from 0 on the right) is worth 2 ** i. Python gives you built-ins to go both ways between int and binary text.

13 IN BINARY
 bit index:     3    2    1    0
 place value:   8    4    2    1
 bits:          1    1    0    1      → 8 + 4 + 0 + 1 = 13
PYTHON — Converting To and From Binary
x = 13
print(bin(x))               # 0b1101      (str with 0b prefix)
print(format(x, 'b'))       # 1101        (no prefix)
print(format(x, '08b'))     # 00001101    (zero-padded to 8 bits)
print(f"{x:#010b}")         # 0b00001101  (f-string, prefix + padding)
print(int('1101', 2))       # 13          (parse binary text)
print(int('0b1101', 2))     # 13          (prefix allowed when base=2)
print(0b1101, 0xFF, 0o17)   # 13 255 15   (binary / hex / octal literals)
print(x.bit_length())       # 4           (bits needed, ignoring sign)
print(bin(-13))             # -0b1101     (sign + magnitude, see Concept 03)
CONCEPT 02

The Six Bitwise Operators

All operators work bit-by-bit on the binary forms. << and >> shift the bits left/right: x << k is x * 2**k and x >> k is x // 2**k (floor division, also for negatives).

a = 12, b = 10
 a        = 1100   (12)
 b        = 1010   (10)
 a & b    = 1000   (8)    AND  → 1 only where BOTH are 1
 a | b    = 1110   (14)   OR   → 1 where EITHER is 1
 a ^ b    = 0110   (6)    XOR  → 1 where they DIFFER
 ~a       = -13           NOT  → flips every bit; in Python ~x == -x - 1
 a << 2   = 110000 (48)   shift left  = multiply by 4
 a >> 2   = 11     (3)    shift right = floor-divide by 4
PYTHON — Operators in Action
a, b = 12, 10
print(a & b, a | b, a ^ b)   # 8 14 6
print(~a)                    # -13
print(a << 2, a >> 2)        # 48 3
print(1 << 10)               # 1024   (fast 2 ** 10)
print(7 >> 1, -7 >> 1)       # 3 -4   (>> floors, like //)

# Python-friendly forms
flags = 0
flags |= 1 << 3              # augmented assignment works: &= |= ^= <<= >>=
print(flags)                 # 8
print(6 & 1 == 0)            # True   (parsed as (6 & 1) == 0)
Precedence (different from C and Java!): in Python, & ^ | bind tighter than comparisons, so x & 1 == 0 means (x & 1) == 0. But + - bind tighter than shifts: 1 << n - 1 is 1 << (n - 1). When in doubt, add parentheses — readers will thank you.
CONCEPT 03

Python Ints: Arbitrary Precision & Negative Numbers

Python ints never overflow — they grow as big as memory allows. Negative numbers behave as if they were written in two’s complement with infinitely many leading 1s. That is why ~x == -x - 1, why -1 & x == x, and why there is no unsigned shift (>>>) in Python. bin() however prints sign + magnitude, not the bit pattern.

-5 AS PYTHON SEES IT
  5  = ...0000 0101
 ~5  = ...1111 1010   = -6     (flip every bit, forever to the left)
 -5  = ...1111 1011   = ~5 + 1 (two's complement)
 -5 & 0xFFFFFFFF  →  1111 1111 1111 1111 1111 1111 1111 1011 = 4294967291
                     (keep only the low 32 bits → "unsigned 32-bit view")
PYTHON — Big Ints, Negatives and 32-bit Masking
print(2 ** 100)            # 1267650600228229401496703205376  (no overflow)
print(~5, -5 - 1)          # -6 -6
print(bin(-5))             # -0b101   (NOT the two's-complement bits)

MASK = 0xFFFFFFFF          # 32 ones
print(-5 & MASK)           # 4294967291
print(format(-5 & MASK, '032b'))  # 11111111111111111111111111111011

def to_signed32(x: int) -> int:
    """Interpret the low 32 bits of x as a signed 32-bit int."""
    x &= MASK
    return x - (1 << 32) if x & (1 << 31) else x

print(to_signed32(4294967291))   # -5
print(to_signed32(2 ** 31))      # -2147483648  (wraps like C int32)
print(to_signed32(7))            # 7

Problems written for 32-bit languages (Reverse Bits, Sum of Two Integers, Number of 1 Bits with negative input) need this masking in Python, otherwise loops on negative numbers never terminate because the leading 1s go on forever.

PYTHON — Add Without + (emulated 32-bit)
def get_sum(a: int, b: int) -> int:
    MASK = 0xFFFFFFFF
    while b & MASK:                      # carry left within 32 bits?
        a, b = a ^ b, (a & b) << 1       # sum without carry, carry
    a &= MASK
    return a if a <= 0x7FFFFFFF else ~(a ^ MASK)   # back to signed

print(get_sum(5, 7))     # 12
print(get_sum(-2, 3))    # 1
print(get_sum(-5, -7))   # -12
TECHNIQUE 01

Check / Set / Clear / Toggle a Bit

Build a mask with a single 1 at position i: 1 << i. Then combine it with the number using the right operator.

x = 1010 (10), i = 2 → mask = 0100
 check   (x >> i) & 1     → 0          is bit i on?
 set     x |  mask        → 1110 (14)  force bit i to 1
 clear   x & ~mask        → 1010 (10)  force bit i to 0
 toggle  x ^  mask        → 1110 (14)  flip bit i
PYTHON — Single-Bit Helpers
def get_bit(x: int, i: int) -> int:
    return (x >> i) & 1

def set_bit(x: int, i: int) -> int:
    return x | (1 << i)

def clear_bit(x: int, i: int) -> int:
    return x & ~(1 << i)

def toggle_bit(x: int, i: int) -> int:
    return x ^ (1 << i)

x = 0b1010
print(get_bit(x, 1), get_bit(x, 2))   # 1 0
print(bin(set_bit(x, 0)))             # 0b1011
print(bin(clear_bit(x, 3)))           # 0b10
print(bin(toggle_bit(x, 2)))          # 0b1110
print(x & 1 == 1)                     # False  (even number: lowest bit is 0)
TECHNIQUE 02

Lowest Set Bit: x & (x - 1) and x & -x

Subtracting 1 flips the lowest 1-bit to 0 and every 0 below it to 1. So x & (x - 1) removes the lowest set bit, and x & -x isolates it. A power of two has exactly one set bit, so removing it leaves 0.

x = 88
 x            = 0101 1000
 x - 1        = 0101 0111
 x & (x - 1)  = 0101 0000   (80)  lowest 1 removed
 -x           = 1010 1000   (two's complement: ~x + 1)
 x & -x       = 0000 1000   (8)   lowest 1 isolated
PYTHON — Power of Two and Lowest Bit
def is_power_of_two(n: int) -> bool:
    return n > 0 and (n & (n - 1)) == 0

print([n for n in range(1, 70) if is_power_of_two(n)])  # [1, 2, 4, 8, 16, 32, 64]
print(88 & (88 - 1))      # 80
print(88 & -88)           # 8
print((88 & -88).bit_length() - 1)   # 3   (index of the lowest set bit)
TECHNIQUE 03

Counting Set Bits

Three ways, from most Pythonic to most “interview”: the string trick, the bit-by-bit loop, and Brian Kernighan’s algorithm which loops once per set bit using x &= x - 1. (Python 3.10+ also has x.bit_count() — not available on 3.7.)

PYTHON — Three Ways to Count 1 Bits
def popcount_str(x: int) -> int:
    return bin(x).count('1')          # simple and fast in CPython

def popcount_loop(x: int) -> int:
    count = 0
    while x:
        count += x & 1                # look at the lowest bit
        x >>= 1                       # O(number of bits)
    return count

def popcount_kernighan(x: int) -> int:
    count = 0
    while x:
        x &= x - 1                    # drop the lowest set bit
        count += 1                    # O(number of SET bits)
    return count

for f in (popcount_str, popcount_loop, popcount_kernighan):
    print(f.__name__, f(0b1011000))   # each prints 3
print(popcount_kernighan(255))   # 8
Negative input: popcount_loop(-1) never ends — -1 >> 1 is still -1. Mask first: popcount_kernighan(-1 & 0xFFFFFFFF) → 32.
TECHNIQUE 04

XOR Tricks

XOR has three magic properties: a ^ a == 0, a ^ 0 == a, and it is commutative and associative. So XOR-ing a whole list cancels every value that appears an even number of times.

XOR CANCELS PAIRS
 4 ^ 1 ^ 2 ^ 1 ^ 2
 = 4 ^ (1 ^ 1) ^ (2 ^ 2)     reorder freely
 = 4 ^   0     ^   0
 = 4                          the unpaired value survives
PYTHON — XOR Patterns
from functools import reduce
from operator import xor

nums = [4, 1, 2, 1, 2]
print(reduce(xor, nums))              # 4   (the value without a twin)

# missing number in 0..n: XOR indices and values together
arr = [3, 0, 1]
print(reduce(xor, arr, 0) ^ reduce(xor, range(len(arr) + 1), 0))   # 2

# opposite signs?  the sign "bit" differs exactly when a ^ b < 0
print((5 ^ -3) < 0, (5 ^ 3) < 0)      # True False

# swap: in Python just use tuple unpacking (the XOR swap is a C trick)
a, b = 3, 9
a, b = b, a
print(a, b)                           # 9 3
TECHNIQUE 05

Enumerating Subsets with a Bitmask

A list of n items has 2ⁿ subsets — exactly the numbers 0 to 2ⁿ - 1. Read each number as a bitmask: bit i = 1 means “item i is in the subset”.

nums = ['a', 'b', 'c']
 mask  bits (c b a)   subset
  0      0 0 0        []
  1      0 0 1        ['a']
  2      0 1 0        ['b']
  3      0 1 1        ['a', 'b']
  4      1 0 0        ['c']
  5      1 0 1        ['a', 'c']
  6      1 1 0        ['b', 'c']
  7      1 1 1        ['a', 'b', 'c']
PYTHON — All Subsets and Submasks
from typing import List

def all_subsets(items: List[str]) -> List[List[str]]:
    n = len(items)
    return [[items[i] for i in range(n) if mask >> i & 1]
            for mask in range(1 << n)]

print(all_subsets(['a', 'b', 'c']))
# [[], ['a'], ['b'], ['a', 'b'], ['c'], ['a', 'c'], ['b', 'c'], ['a', 'b', 'c']]

# iterate every submask of a mask (classic in bitmask DP)
mask = 0b1011
sub = mask
subs = []
while sub:
    subs.append(format(sub, '04b'))
    sub = (sub - 1) & mask
print(subs)   # ['1011', '1010', '1001', '1000', '0011', '0010', '0001']

# a bitmask as a tiny set: visited cities 0 and 2
visited = (1 << 0) | (1 << 2)
print(bool(visited & (1 << 2)), bool(visited & (1 << 1)))   # True False
Size limit: 2ⁿ grows fast — bitmask enumeration is practical up to about n = 20 (~1 million masks). For “all subsets” in Python, itertools.combinations for each size is an equally valid alternative.
Find the unique element: XOR everything
Is n a power of two: n > 0 and n & (n - 1) == 0
Count set bits: bin(n).count('1') or Kernighan
Subsets / bitmask DP: for mask in range(1 << n)
32-bit behaviour: mask with & 0xFFFFFFFF
Multiply / divide by 2ᵏ: << k and >> k
