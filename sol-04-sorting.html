01Sort Colors (Dutch National Flag)MEDIUM
Problem: Sort a list of 0s, 1s, and 2s in place without the built-in sort.

Think: Three-pointer approach. low pointer tracks where 0s go, high pointer tracks where 2s go, mid walks through. Swap 0s to the left, 2s to the right, 1s stay in middle.
1
low=0, mid=0, high=end. mid walks through the list.
2
If nums[mid]==0 → swap with nums[low], move both low and mid forward.
3
If nums[mid]==1 → it's in the right zone, just move mid forward.
4
If nums[mid]==2 → swap with nums[high], move high back. Don't move mid (swapped value unchecked).
Time: O(n)
Space: O(1)
SOLUTION
from typing import List

def sort_colors(nums: List[int]) -> None:
    """Sort 0s, 1s and 2s in place. Returns None, just like list.sort()."""
    low, mid, high = 0, 0, len(nums) - 1

    while mid <= high:
        if nums[mid] == 0:
            # 0 belongs at the front
            nums[low], nums[mid] = nums[mid], nums[low]
            low += 1
            mid += 1
        elif nums[mid] == 1:
            # 1 belongs in the middle, just advance
            mid += 1
        else:
            # 2 belongs at the back
            nums[mid], nums[high] = nums[high], nums[mid]
            high -= 1   # don't advance mid — need to check swapped value

arr = [2, 0, 2, 1, 1, 0]
sort_colors(arr)
print(arr)   # [0, 0, 1, 1, 2, 2]
02Merge IntervalsMEDIUM
Think: Sort intervals by start time. Then walk through — if current interval's start ≤ previous interval's end, they overlap → merge by extending the end. Otherwise, start a new group.
Time: O(n log n)
Space: O(n)
SOLUTION
from typing import List

def merge(intervals: List[List[int]]) -> List[List[int]]:
    if not intervals:
        return []

    # Sort by start time first — key= instead of a comparator
    intervals.sort(key=lambda iv: iv[0])

    result = [intervals[0]]          # start with first interval

    for start, end in intervals[1:]:  # unpack each [start, end] pair
        last = result[-1]            # negative index → last element

        if start <= last[1]:
            # Overlapping — merge by extending the end
            last[1] = max(last[1], end)
        else:
            # No overlap — add as new interval
            result.append([start, end])

    return result

print(merge([[1, 3], [2, 6], [8, 10], [15, 18]]))
# [[1, 6], [8, 10], [15, 18]]
03Kth Largest Element in ArrayMEDIUM
Think: Simplest way: sort descending, return index k-1. Better: keep a min-heap of size k with heapq — its smallest element is the kth largest, O(n log k). Optimal on average: QuickSelect — partition like quicksort but only recurse into the side containing index k. Average O(n).
SOLUTION — Simple Sort
from typing import List

def find_kth_largest(nums: List[int], k: int) -> int:
    nums.sort(reverse=True)   # sort descending, in place
    return nums[k - 1]        # kth largest is at index k-1

print(find_kth_largest([3, 2, 1, 5, 6, 4], 2))   # 5
SOLUTION — Min-Heap of Size k (O(n log k))
import heapq
from typing import List

def find_kth_largest_heap(nums: List[int], k: int) -> int:
    heap = []                      # heapq is a MIN-heap: heap[0] is the smallest
    for n in nums:
        heapq.heappush(heap, n)
        if len(heap) > k:
            heapq.heappop(heap)    # drop the smallest → keep the k largest
    return heap[0]                 # smallest of the k largest = kth largest

print(find_kth_largest_heap([3, 2, 1, 5, 6, 4], 2))   # 5
print(heapq.nlargest(2, [3, 2, 1, 5, 6, 4])[-1])      # 5  — same idea, one line
04Sort a Nearly Sorted ArrayMEDIUM
Problem: Every element is at most k positions away from its place in sorted order (a "k-sorted" array). Sort it faster than O(n log n).

Think: The smallest element must be somewhere in the first k+1 slots. So keep a min-heap of size k+1 sliding along the list: pop the smallest (it's final), push the next element. Each heap operation costs O(log k) instead of O(log n).
1
Put the first k+1 elements in a list and heapq.heapify it — O(k).
2
For each remaining element: push it and pop the smallest in one call with heapq.heappushpop. The popped value goes to the output.
3
When the input runs out, pop everything left in the heap (already in order).
Time: O(n log k)
Space: O(k)
SOLUTION — Min-Heap of Size k+1
import heapq
from typing import List

def sort_k_sorted(nums: List[int], k: int) -> List[int]:
    """Each element is at most k positions away from its sorted spot."""
    heap = nums[:k + 1]       # the smallest element must be in here
    heapq.heapify(heap)       # O(k)
    result = []

    for x in nums[k + 1:]:
        result.append(heapq.heappushpop(heap, x))   # push x, pop the smallest → it's final

    while heap:
        result.append(heapq.heappop(heap))          # drain what's left, smallest first

    return result

print(sort_k_sorted([6, 5, 3, 2, 8, 10, 9], 3))   # [2, 3, 5, 6, 8, 9, 10]
print(sort_k_sorted([2, 1, 4, 3, 6, 5], 1))       # [1, 2, 3, 4, 5, 6]
print(sort_k_sorted([], 2))                           # []
