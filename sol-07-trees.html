SOLUTIONS 08

Tree Solutions

Think recursively — every tree problem is: do something at current node, recurse left, recurse right.

Shared setup: every solution below uses this TreeNode class (the same one LeetCode's Python template uses).
PYTHON — TreeNode
from collections import deque
from typing import List, Optional

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
01Invert Binary TreeEASY
Think: At each node, swap left and right children. Then do the same recursively for both subtrees. Base case: None node → do nothing.
Time: O(n)
Space: O(h)
SOLUTION
def invert_tree(root: Optional[TreeNode]) -> Optional[TreeNode]:
    if not root:
        return None  # base case

    # Swap left and right children (tuple unpacking — no temp variable)
    root.left, root.right = root.right, root.left

    # Recursively invert both subtrees
    invert_tree(root.left)
    invert_tree(root.right)

    return root
#     4              4
#    / \    →       / \
#   2   7          7   2
#  / \ / \        / \ / \
# 1  3 6  9      9  6 3  1

t = TreeNode(4, TreeNode(2, TreeNode(1), TreeNode(3)),
                TreeNode(7, TreeNode(6), TreeNode(9)))
t = invert_tree(t)
print(t.val, t.left.val, t.right.val, t.left.left.val)  # 4 7 2 9
02Symmetric TreeEASY
Think: A tree is symmetric if its left and right subtrees are mirror images. Compare left.left with right.right, and left.right with right.left simultaneously. A nested def keeps the helper private to the function.
Time: O(n)
Space: O(h)
SOLUTION
def is_symmetric(root: Optional[TreeNode]) -> bool:
    def is_mirror(left: Optional[TreeNode], right: Optional[TreeNode]) -> bool:
        if not left and not right:
            return True   # both None → symmetric
        if not left or not right:
            return False  # one None → not symmetric

        return (
            left.val == right.val                # values match
            and is_mirror(left.left, right.right)  # outer pair matches
            and is_mirror(left.right, right.left)  # inner pair matches
        )

    return root is None or is_mirror(root.left, root.right)

sym = TreeNode(1, TreeNode(2, TreeNode(3), TreeNode(4)),
                  TreeNode(2, TreeNode(4), TreeNode(3)))
print(is_symmetric(sym))                                # True
print(is_symmetric(TreeNode(1, TreeNode(2), TreeNode(3))))  # False
03Validate BSTMEDIUM
Think: At every node, there's a valid range [low, high] it must fall within. The root can be anything (-∞ to +∞, i.e. float('-inf') to float('inf')). Going left tightens the upper bound; going right tightens the lower bound. Pass these bounds down through recursion.
Time: O(n)
Space: O(h)
SOLUTION
def is_valid_bst(root: Optional[TreeNode],
                 low: float = float('-inf'),
                 high: float = float('inf')) -> bool:
    if not root:
        return True  # empty tree is valid

    # Current node must be strictly between low and high (chained comparison!)
    if not (low < root.val < high):
        return False

    # Left subtree: all values must be < root.val (new high)
    # Right subtree: all values must be > root.val (new low)
    return (is_valid_bst(root.left, low, root.val) and
            is_valid_bst(root.right, root.val, high))

# Example: tree [2,1,3]
#     2
#    / \   → is_valid_bst(2, -∞, +∞)
#   1   3     → is_valid_bst(1, -∞, 2) ✓  (1 < 2)
#              → is_valid_bst(3, 2, +∞) ✓  (3 > 2)
# Result: True
print(is_valid_bst(TreeNode(2, TreeNode(1), TreeNode(3))))  # True
print(is_valid_bst(TreeNode(5, TreeNode(1),
                            TreeNode(4, TreeNode(3), TreeNode(6)))))  # False
04Lowest Common Ancestor of a BSTMEDIUM
Think: In a BST, the LCA is the first node where p and q go in DIFFERENT directions (or one of them IS the node). If both are smaller → go left. If both are larger → go right. Otherwise, we're at the LCA.
Time: O(h)
Space: O(1)
SOLUTION — BST version
def lowest_common_ancestor(root: Optional[TreeNode],
                           p: TreeNode, q: TreeNode) -> Optional[TreeNode]:
    while root:
        if p.val < root.val and q.val < root.val:
            root = root.left   # both in left subtree
        elif p.val > root.val and q.val > root.val:
            root = root.right  # both in right subtree
        else:
            return root        # they split here → this is the LCA!
    return None

#        6
#      /   \
#     2     8
#    / \   / \
#   0   4 7   9
n2, n8 = TreeNode(2, TreeNode(0), TreeNode(4)), TreeNode(8, TreeNode(7), TreeNode(9))
bst = TreeNode(6, n2, n8)
print(lowest_common_ancestor(bst, n2, n8).val)        # 6
print(lowest_common_ancestor(bst, n2, n2.right).val)  # 2
05Binary Tree Right Side ViewMEDIUM
Think: Level-order traversal (BFS) with a collections.deque. At each level, the LAST node dequeued is what you'd see from the right side. Collect those.
Time: O(n)
Space: O(w)
SOLUTION
def right_side_view(root: Optional[TreeNode]) -> List[int]:
    if not root:
        return []
    result = []
    queue = deque([root])

    while queue:
        level_size = len(queue)

        for i in range(level_size):
            node = queue.popleft()  # O(1) — list.pop(0) would be O(n)

            # Last node of this level is what we see from right
            if i == level_size - 1:
                result.append(node.val)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)

    return result

#     1
#    / \
#   2   3
#    \   \
#     5   4
tree = TreeNode(1, TreeNode(2, None, TreeNode(5)), TreeNode(3, None, TreeNode(4)))
print(right_side_view(tree))  # [1, 3, 4]
06Maximum Depth of Binary TreeEASY
Think: The recursive one-liner 1 + max(depth(left), depth(right)) is shown on the Trees page. Here is the iterative alternative: a level-order BFS where every completed level adds 1 to the depth. It never touches the recursion limit, even on a degenerate tree.
Time: O(n)
Space: O(w)
SOLUTION — BFS, count the levels
def max_depth(root: Optional[TreeNode]) -> int:
    if not root:
        return 0
    depth = 0
    queue = deque([root])
    while queue:
        depth += 1                       # one more level
        for _ in range(len(queue)):
            node = queue.popleft()
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
    return depth

print(max_depth(tree))   # 3  (tree from the previous solution)
print(max_depth(None))   # 0
07Serialize and Deserialize Binary TreeHARD
Think: A preorder traversal that also writes a marker (#) for every missing child describes the tree uniquely. To rebuild, read the tokens back in the same preorder: each token is either # (return None) or a value whose left and right subtrees follow immediately. An iterator over the tokens remembers the position between recursive calls.
Time: O(n)
Space: O(n)
SOLUTION — Preorder with "#" markers for None
class Codec:
    def serialize(self, root: Optional[TreeNode]) -> str:
        out = []

        def dfs(node: Optional[TreeNode]) -> None:
            if not node:
                out.append("#")      # marker for a missing child
                return
            out.append(str(node.val))
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return ",".join(out)

    def deserialize(self, data: str) -> Optional[TreeNode]:
        tokens = iter(data.split(","))

        def build() -> Optional[TreeNode]:
            tok = next(tokens)
            if tok == "#":
                return None
            node = TreeNode(int(tok))
            node.left = build()        # same order as serialize
            node.right = build()
            return node

        return build()

codec = Codec()
s = codec.serialize(tree)
print(s)                                       # 1,2,#,5,#,#,3,#,4,#,#
print(codec.serialize(codec.deserialize(s)) == s)  # True (round trip)
print(right_side_view(codec.deserialize(s)))   # [1, 3, 4]
Python tip: next(tokens) on a shared iterator replaces a manual index counter — no nonlocal i needed. For very deep trees, swap the recursion for an explicit stack (see the recursion-limit note on the Trees page).
