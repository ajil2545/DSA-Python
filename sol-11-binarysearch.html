01First Bad VersionEASY
Problem: Versions 1..n. Starting from some version k, all are bad. Find k with the minimum number of calls to the API is_bad_version(version).

Think: Binary search on the version number. If mid is bad, the first bad could be mid or earlier → hi = mid. If mid is good, it's after → lo = mid+1. When lo == hi, we found it.
Time: O(log n)
Space: O(1)
SOLUTION
from typing import Callable


def first_bad_version(n: int, is_bad_version: Callable[[int], bool]) -> int:
    lo, hi = 1, n

    while lo < hi:  # ← < not <=  (we want lo == hi at end)
        mid = (lo + hi) // 2  # no overflow worries — Python ints are unbounded

        if is_bad_version(mid):
            hi = mid        # bad → first bad is mid or before
        else:
            lo = mid + 1    # good → first bad is after mid

    return lo  # lo == hi == first bad version


# The "API": versions 4 and later are bad
print(first_bad_version(5, lambda v: v >= 4))  # 4
print(first_bad_version(1, lambda v: v >= 1))  # 1
02Find Minimum in Rotated Sorted ArrayMEDIUM
Problem: A sorted array of unique values was rotated at an unknown pivot. Find its minimum element in O(log n).

Think: In a rotated sorted array, the minimum is where the "break" is. Compare nums[mid] with nums[hi]: if nums[mid] > nums[hi], the minimum is in the RIGHT half (the break is there). Otherwise, it's in the left half (or at mid).
Time: O(log n)
Space: O(1)
SOLUTION
from typing import List


def find_min(nums: List[int]) -> int:
    lo, hi = 0, len(nums) - 1

    while lo < hi:
        mid = (lo + hi) // 2

        if nums[mid] > nums[hi]:
            # Mid is in the "bigger" left portion → min is to the right
            lo = mid + 1
        else:
            # Mid is in the "smaller" right portion → min is here or left
            hi = mid

    return nums[lo]


print(find_min([3, 4, 5, 1, 2]))        # 1
print(find_min([4, 5, 6, 7, 0, 1, 2]))  # 0
# Sanity check (O(n), but great for testing): min() built-in
print(min([4, 5, 6, 7, 0, 1, 2]))       # 0
03Koko Eating BananasMEDIUM
Problem: Koko can eat k bananas/hour. Find minimum k to eat all piles within h hours.

Think: Binary search on the ANSWER (k). Min possible k = 1, max = max pile size. For a given k, check if it's feasible. Hours needed = sum of ceil(pile/k) for all piles. If ≤ h, k works.
1
Search space: k from 1 to max(piles).
2
For each mid k, calculate total hours: sum(ceil(pile/k)).
3
If hours ≤ h, k works — try smaller (hi = mid).
4
If hours > h, k too slow — try bigger (lo = mid+1).
Time: O(n log m) m=max pile
Space: O(1)
SOLUTION
from typing import List


def min_eating_speed(piles: List[int], h: int) -> int:
    lo, hi = 1, max(piles)

    while lo < hi:
        mid = (lo + hi) // 2

        # Hours needed at speed mid. -(-p // k) is integer ceil(p / k):
        # exact, no floats, no math.ceil import needed.
        hours = sum(-(-pile // mid) for pile in piles)

        if hours <= h:
            hi = mid      # fast enough — can we do with less?
        else:
            lo = mid + 1  # too slow — need to eat faster

    return lo


print(min_eating_speed([3, 6, 7, 11], 8))  # 4
04Median of Two Sorted ArraysHARD
Problem: Given two sorted arrays of sizes m and n, return the median of the combined data in O(log(m + n)).

Think: Binary search on the partition of the SMALLER array. Find a cut so that: left part of nums1 + left part of nums2 = half the total elements, AND all left elements ≤ all right elements. The median is derived from the boundary values.
Time: O(log(min(m, n)))
Space: O(1)
SOLUTION
from typing import List


def find_median_sorted_arrays(nums1: List[int], nums2: List[int]) -> float:
    # Ensure nums1 is the smaller array (binary search on smaller)
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    m, n = len(nums1), len(nums2)
    INF = float('inf')
    lo, hi = 0, m

    while lo <= hi:
        part_x = (lo + hi) // 2               # partition in nums1
        part_y = (m + n + 1) // 2 - part_x     # partition in nums2

        max_left_x  = -INF if part_x == 0 else nums1[part_x - 1]
        min_right_x =  INF if part_x == m else nums1[part_x]
        max_left_y  = -INF if part_y == 0 else nums2[part_y - 1]
        min_right_y =  INF if part_y == n else nums2[part_y]

        if max_left_x <= min_right_y and max_left_y <= min_right_x:
            # Perfect partition found!
            if (m + n) % 2 == 0:
                return (max(max_left_x, max_left_y) + min(min_right_x, min_right_y)) / 2
            return float(max(max_left_x, max_left_y))
        elif max_left_x > min_right_y:
            hi = part_x - 1
        else:
            lo = part_x + 1

    raise ValueError("input arrays must be sorted")


print(find_median_sorted_arrays([1, 3], [2]))     # 2.0
print(find_median_sorted_arrays([1, 2], [3, 4]))  # 2.5
# Note: / always returns a float in Python 3; // is floor division.
