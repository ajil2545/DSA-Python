01 Two Sum (unsorted) EASY
Problem: Given array of numbers, return indices of two numbers that add up to target.

Think: Brute force checks every pair — O(n²). Instead, for each number ask: "have I already seen the number I need?" Use a dict to answer that in O(1).

Key insight: complement = target - current. If complement is in our dict, we found our pair!
1
Walk through the list one number at a time with enumerate() (index + value).
2
For each number, calculate what number we'd NEED to reach target (complement = target - num).
3
Check if that complement was seen before (complement in seen). If yes → return both indices.
4
If not, store current number and its index in the dict for future lookups.
Time: O(n)
Space: O(n)
SOLUTION
from typing import Dict, List

def two_sum(nums: List[int], target: int) -> List[int]:
    # dict stores: number → its index
    seen: Dict[int, int] = {}

    for i, num in enumerate(nums):
        complement = target - num

        if complement in seen:  # O(1) average dict lookup
            # Found it! Return the stored index and current index
            return [seen[complement], i]

        # Haven't found pair yet — store this number for later
        seen[num] = i

    return []  # no pair (problem guarantees one exists)

# Walk-through with nums=[2,7,11,15], target=9:
# i=0: num=2, complement=7. seen={}. Not found. Store {2: 0}
# i=1: num=7, complement=2. seen={2: 0}. Found! Return [0, 1] ✓

print(two_sum([2, 7, 11, 15], 9))  # [0, 1]
print(two_sum([3, 2, 4], 6))       # [1, 2]
02 Best Time to Buy and Sell Stock EASY
Problem: Given array of stock prices per day, find max profit from one buy + one sell.

Think: You must buy BEFORE you sell. Track the minimum price seen so far — that's your best buy day. Then profit = today's price - min_so_far. Keep track of max profit seen.
1
Keep track of the lowest price seen so far (best day to buy), starting at float('inf').
2
For each day, calculate profit if we sold today: price - min_price.
3
Update max_profit if today's profit is better.
4
Update min_price if today's price is lower.
Time: O(n)
Space: O(1)
SOLUTION
from typing import List

def max_profit(prices: List[int]) -> int:
    min_price = float("inf")  # best price to buy at (infinity: anything is cheaper)
    best = 0                    # best profit found so far

    for price in prices:
        if price < min_price:
            min_price = price  # found a cheaper buy day!
        else:
            # What's our profit if we sell today?
            best = max(best, price - min_price)

    return best

# Walk-through: [7,1,5,3,6,4]
# price=7: min_price=7, profit=0
# price=1: min_price=1 (cheaper buy!)
# price=5: profit=5-1=4, best=4
# price=3: profit=3-1=2, best still 4
# price=6: profit=6-1=5, best=5 ✓
# price=4: profit=3, best still 5

print(max_profit([7, 1, 5, 3, 6, 4]))  # 5
print(max_profit([7, 6, 4, 3, 1]))     # 0 (prices only drop)
03 Contains Duplicate EASY
Problem: Return True if any value appears at least twice.

Think: A set only stores unique values. If the number is already in the set (an O(1) check), we found a duplicate — return True immediately. Checking num in nums_so_far on a list instead would be O(n) per check → O(n²) total.
Time: O(n)
Space: O(n)
SOLUTION
from typing import List

def contains_duplicate(nums: List[int]) -> bool:
    seen = set()

    for num in nums:
        if num in seen:
            return True  # seen before → duplicate!
        seen.add(num)

    return False  # got through all without a duplicate

# One-liner (idiomatic Python, but always builds the full set — no early exit):
def contains_dup2(nums: List[int]) -> bool:
    return len(set(nums)) != len(nums)

print(contains_duplicate([1, 2, 3, 1]))  # True
print(contains_duplicate([1, 2, 3, 4]))  # False
print(contains_dup2([1, 2, 3, 1]))       # True
04 Maximum Subarray (Kadane's Algorithm) MEDIUM
Problem: Find the contiguous subarray with the largest sum.

Think: At each position, make a decision: "Is it better to extend the current subarray, or start fresh from this element?" If the running sum becomes negative, it's dragging us down — cut it off and start over.
1
Start with current sum = first element, max sum = first element.
2
For each next element: should we ADD it to our current subarray, or START FRESH?
3
current_sum = max(element, current_sum + element). If current_sum was negative, starting fresh is better.
4
Update max_sum whenever current_sum beats it.
Time: O(n)
Space: O(1)
SOLUTION — Kadane's Algorithm
from typing import List

def max_sub_array(nums: List[int]) -> int:
    current_sum = max_sum = nums[0]  # chained assignment

    for i in range(1, len(nums)):  # (nums[1:] would copy the list → O(n) extra space)
        # Decision: extend current subarray OR start fresh here
        current_sum = max(nums[i], current_sum + nums[i])
        max_sum = max(max_sum, current_sum)

    return max_sum

# Walk-through: [-2,1,-3,4,-1,2,1,-5,4]
# i=1: cur=max(1, -2+1)=max(1,-1)=1,     max=1
# i=2: cur=max(-3,1-3)=max(-3,-2)=-2,    max=1
# i=3: cur=max(4,-2+4)=max(4,2)=4,       max=4
# i=4: cur=max(-1,4-1)=max(-1,3)=3,      max=4
# i=5: cur=max(2,3+2)=max(2,5)=5,        max=5
# i=6: cur=max(1,5+1)=max(1,6)=6,        max=6 ✓
# i=7: cur=max(-5,6-5)=max(-5,1)=1,     max=6
# i=8: cur=max(4,1+4)=max(4,5)=5,        max=6
# Answer: 6 (subarray [4,-1,2,1])

print(max_sub_array([-2, 1, -3, 4, -1, 2, 1, -5, 4]))  # 6
05 3Sum MEDIUM
Problem: Find all unique triplets [a,b,c] in array where a+b+c = 0.

Think: Sort first! Fix one number (a), then use Two Pointers to find b+c = -a in the remaining sorted portion. Skip duplicates to avoid repeated triplets.
1
Sort the list (nums.sort() sorts in place; sorted(nums) returns a new list). Now we can use two pointers on the rest.
2
Fix index i (the first number). Use left=i+1 and right=end as two pointers.
3
If sum == 0 → save triplet, move both pointers inward (skip duplicates).
4
If sum < 0 → move left up (need bigger). If sum > 0 → move right down (need smaller).
Time: O(n²)
Space: O(1)
SOLUTION
from typing import List

def three_sum(nums: List[int]) -> List[List[int]]:
    nums.sort()  # sort first! in place, ascending, O(n log n)
    result = []
    n = len(nums)

    for i in range(n - 2):
        # Skip duplicate values for i
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left, right = i + 1, n - 1

        while left < right:
            total = nums[i] + nums[left] + nums[right]

            if total == 0:
                result.append([nums[i], nums[left], nums[right]])
                # Skip duplicates for left and right
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1
            elif total < 0:
                left += 1   # need bigger sum
            else:
                right -= 1  # need smaller sum

    return result

print(three_sum([-1, 0, 1, 2, -1, -4]))
# [[-1, -1, 2], [-1, 0, 1]]
06 Container With Most Water MEDIUM
Problem: Given heights of walls, find two walls that form a container holding the most water.

Think: Water volume = width × min(left height, right height). Start with widest container (left=0, right=end). Moving the TALLER wall inward can only make things worse (width shrinks, height can't improve). Always move the SHORTER wall.
Time: O(n)
Space: O(1)
SOLUTION
from typing import List

def max_water(heights: List[int]) -> int:
    left, right = 0, len(heights) - 1
    best = 0

    while left < right:
        width = right - left
        height = min(heights[left], heights[right])
        best = max(best, width * height)

        # Move the shorter wall (taller wall moving can only hurt)
        if heights[left] < heights[right]:
            left += 1
        else:
            right -= 1

    return best

print(max_water([1, 8, 6, 2, 5, 4, 8, 3, 7]))  # 49
07 Trapping Rain Water HARD
Problem: Given elevation heights, compute how much rainwater gets trapped.

Think: Water at position i is trapped up to min(max_left, max_right) - height[i]. Use two pointers: compare the two current walls. The SHORTER side is the bottleneck — the other side already has a wall at least as tall, so the water level on the shorter side is just its own running max. Process that side.
1
Two pointers from both ends. Track max_left and max_right seen so far.
2
Process the side whose current height is smaller — update its running max, then water at that position = max - current height.
3
Move that pointer inward and repeat.
Time: O(n)
Space: O(1)
SOLUTION
from typing import List

def trap(height: List[int]) -> int:
    left, right = 0, len(height) - 1
    max_left = max_right = 0
    water = 0

    while left < right:
        if height[left] <= height[right]:
            # Left side is the bottleneck
            max_left = max(max_left, height[left])
            water += max_left - height[left]  # water above this cell
            left += 1
        else:
            # Right side is the bottleneck
            max_right = max(max_right, height[right])
            water += max_right - height[right]
            right -= 1

    return water

print(trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]))  # 6
