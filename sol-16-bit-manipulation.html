Bit Manipulation Solutions

XOR folds, Kernighan counts, 32-bit masking and bitmask subsets — every practice problem solved in Python.

01Single NumberEASY
Think: Every number appears twice except one. Since a ^ a == 0 and a ^ 0 == a, XOR-ing the whole list cancels all the pairs and leaves the single number — O(1) space, unlike a set or Counter.
1
Start with result = 0.
2
XOR every number into result.
3
Return result (or one line: reduce(xor, nums)).
Time: O(n)
Space: O(1)
SOLUTION — XOR Fold
from functools import reduce
from operator import xor
from typing import List

def single_number(nums: List[int]) -> int:
    result = 0
    for x in nums:
        result ^= x
    return result

def single_number_oneliner(nums: List[int]) -> int:
    return reduce(xor, nums, 0)

print(single_number([2, 2, 1]))              # 1
print(single_number([4, 1, 2, 1, 2]))        # 4
print(single_number_oneliner([-3, 7, -3]))   # 7
02Number of 1 BitsEASY
Think: Count set bits. Brian Kernighan: n &= n - 1 deletes the lowest set bit, so the loop runs once per 1-bit. In Python, a negative input must first be masked to 32 bits or the loop never terminates.
1
Mask: n &= 0xFFFFFFFF (no-op for normal non-negative input).
2
While n: n &= n - 1, count += 1.
3
Return count. Pythonic alternative: bin(n).count('1').
Time: O(set bits) ≤ O(32)
Space: O(1)
SOLUTION — Brian Kernighan
def hamming_weight(n: int) -> int:
    n &= 0xFFFFFFFF            # treat as unsigned 32-bit
    count = 0
    while n:
        n &= n - 1             # remove lowest set bit
        count += 1
    return count

print(hamming_weight(11))           # 3   (1011)
print(hamming_weight(128))          # 1   (10000000)
print(hamming_weight(2147483645))   # 30
print(hamming_weight(-1))           # 32  (all 32 bits set)
print(bin(11).count('1'))           # 3   (built-in shortcut)
03Counting BitsEASY
Think: Return the popcount of every number 0..n in O(n). Reuse earlier answers (DP): i >> 1 is i with its last bit dropped and is smaller than i, so bits[i] = bits[i >> 1] + (i & 1).
1
Create bits = [0] * (n + 1).
2
For i from 1 to n: bits[i] = bits[i >> 1] + (i & 1).
3
Alternative recurrence: bits[i] = bits[i & (i - 1)] + 1.
Time: O(n)
Space: O(n) for the output
SOLUTION — DP on Bits
from typing import List

def count_bits(n: int) -> List[int]:
    bits = [0] * (n + 1)
    for i in range(1, n + 1):
        bits[i] = bits[i >> 1] + (i & 1)
    return bits

def count_bits_kernighan(n: int) -> List[int]:
    bits = [0] * (n + 1)
    for i in range(1, n + 1):
        bits[i] = bits[i & (i - 1)] + 1
    return bits

print(count_bits(2))              # [0, 1, 1]
print(count_bits(5))              # [0, 1, 1, 2, 1, 2]
print(count_bits_kernighan(5))    # [0, 1, 1, 2, 1, 2]
04Power of TwoEASY
Think: A power of two has exactly one set bit (1, 10, 100, ...). n & (n - 1) clears the lowest set bit, so the result is 0 only when there was a single bit. Guard against 0 and negatives with n > 0.
1
Return False if n <= 0.
2
Return (n & (n - 1)) == 0.
Time: O(1)
Space: O(1)
SOLUTION — Single Set Bit
def is_power_of_two(n: int) -> bool:
    return n > 0 and (n & (n - 1)) == 0

def is_power_of_two_alt(n: int) -> bool:
    return n > 0 and bin(n).count('1') == 1

print(is_power_of_two(1))      # True   (2 ** 0)
print(is_power_of_two(16))     # True
print(is_power_of_two(3))      # False
print(is_power_of_two(0))      # False
print(is_power_of_two(-16))    # False
print(is_power_of_two_alt(1024))   # True
05Missing NumberEASY
Think: The list holds n distinct numbers from 0..n with one missing. XOR every index 0..n with every value: present numbers appear twice and cancel, the missing one survives. (The sum formula n*(n+1)//2 - sum(nums) also works and is safe in Python because ints never overflow.)
1
Start missing = len(nums) (covers the index n, which has no slot).
2
For each i, x in enumerate(nums): missing ^= i ^ x.
3
Return missing.
Time: O(n)
Space: O(1)
SOLUTION — XOR Indices with Values
from typing import List

def missing_number(nums: List[int]) -> int:
    missing = len(nums)
    for i, x in enumerate(nums):
        missing ^= i ^ x
    return missing

def missing_number_sum(nums: List[int]) -> int:
    n = len(nums)
    return n * (n + 1) // 2 - sum(nums)

print(missing_number([3, 0, 1]))                     # 2
print(missing_number([0, 1]))                        # 2
print(missing_number([9, 6, 4, 2, 3, 5, 7, 0, 1]))   # 8
print(missing_number_sum([9, 6, 4, 2, 3, 5, 7, 0, 1]))   # 8
06Reverse BitsEASY
Think: Reverse the 32-bit pattern of an unsigned integer. Pop the lowest bit of n and push it onto the low end of result, 32 times. Because the count is fixed at 32, leading zeros are handled automatically. The string version (format(n, '032b')[::-1]) is a neat Python alternative.
1
result = 0.
2
Repeat 32 times: result = (result << 1) | (n & 1), then n >>= 1.
3
Return result.
Time: O(32) = O(1)
Space: O(1)
SOLUTION — Bit by Bit (and a string one-liner)
def reverse_bits(n: int) -> int:
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)   # append n's lowest bit
        n >>= 1
    return result

def reverse_bits_str(n: int) -> int:
    return int(format(n, '032b')[::-1], 2)

print(reverse_bits(43261596))        # 964176192
print(reverse_bits(4294967293))      # 3221225471
print(reverse_bits_str(43261596))    # 964176192
print(format(43261596, '032b'))      # 00000010100101000001111010011100
print(format(964176192, '032b'))     # 00111001011110000010100101000000
07Subsets (via bitmask)MEDIUM
Think: n items → 2ⁿ subsets → the integers 0 .. 2ⁿ - 1. Bit i of mask decides whether nums[i] is in the subset. No recursion needed; the output order is the binary counting order.
1
Loop mask over range(1 << n).
2
Build [nums[i] for i in range(n) if mask >> i & 1].
3
Collect every subset (2ⁿ of them, each up to n long).
Time: O(2ⁿ · n)
Space: O(2ⁿ · n) for the output
SOLUTION — Bitmask Enumeration
from typing import List

def subsets(nums: List[int]) -> List[List[int]]:
    n = len(nums)
    result = []
    for mask in range(1 << n):
        result.append([nums[i] for i in range(n) if (mask >> i) & 1])
    return result

print(subsets([1, 2, 3]))
# [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]
print(subsets([0]))         # [[], [0]]
print(len(subsets(list(range(10)))))   # 1024
CHECK — same set of subsets as itertools
from itertools import combinations

def subsets(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if (mask >> i) & 1] for mask in range(1 << n)]

nums = [1, 2, 3]
via_itertools = [list(c) for k in range(len(nums) + 1) for c in combinations(nums, k)]
print(sorted(subsets(nums)) == sorted(via_itertools))   # True
