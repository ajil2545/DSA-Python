CONCEPT 01

Stack in Python

A Python list is a perfect stack out of the box. append() adds to the top (the end), pop() removes from the top — both amortized O(1). Peek with stack[-1]. Never use insert(0, x) / pop(0) on a stack — those shift every element and are O(n).

STACK VISUALIZATION
  append(3)   append(7)   append(1)   pop()       stack[-1]
                          ┌───┐
              ┌───┐       │ 1 │       ┌───┐       ┌───┐
  ┌───┐       │ 7 │       │ 7 │       │ 7 │       │ 7 │
  │ 3 │       │ 3 │       │ 3 │       │ 3 │       │ 3 │
  └───┘       └───┘       └───┘       └───┘       └───┘
                          top = 1     returns 1   returns 7
                                                  (no removal)
PYTHON — Stack Implementation
# Using a list as a stack
stack = []

stack.append(3)   # [3]
stack.append(7)   # [3, 7]
stack.append(1)   # [3, 7, 1]

stack.pop()       # removes 1 → [3, 7]
print(stack[-1])  # peek → 7 (no removal)
print(len(stack)) # 2
if stack:         # empty list is falsy — idiomatic "is not empty" check
    print("not empty")

# ─────────────────────────────────────────
# Clean Stack class (for clarity)
from typing import Any, List

class Stack:
    def __init__(self) -> None:
        self.items: List[Any] = []

    def push(self, val: Any) -> None:
        self.items.append(val)

    def pop(self) -> Any:
        return self.items.pop()      # raises IndexError if empty

    def peek(self) -> Any:
        return self.items[-1]

    def is_empty(self) -> bool:
        return not self.items

    def __len__(self) -> int:          # enables len(s)
        return len(self.items)

s = Stack()
s.push(1); s.push(2)
print(s.pop(), s.peek(), len(s))  # 2 1 1
Python note: list.pop() on an empty list raises IndexError — guard with if stack:. collections.deque also works as a stack (append/pop), but a plain list is the idiomatic, fastest choice for LIFO. Python's own recursion uses a call stack limited to ~1000 frames (sys.getrecursionlimit()), which is why deep DFS is often rewritten with an explicit list-stack.
TECHNIQUE 01

Balanced Parentheses

Classic stack problem. Push every opening bracket. When you see a closing bracket, pop and check if it matches. If anything's left over at the end, it's invalid.

EXAMPLE — Valid Parentheses
def is_valid(s: str) -> bool:
    stack = []
    pairs = {')': '(', '}': '{', ']': '['}

    for ch in s:
        if ch in '([{':
            stack.append(ch)          # opening → push
        else:
            # closing → check top matches (empty stack → mismatch)
            if not stack or stack.pop() != pairs[ch]:
                return False

    return not stack  # must be empty

print(is_valid("()[]{}"))  # True
print(is_valid("(]"))      # False
print(is_valid("{[]}"))    # True
TECHNIQUE 02

Monotonic Stack

A stack that maintains elements in increasing or decreasing order. Pop elements that violate the order before pushing. Used to solve "next greater element"-type problems in O(n) — each index is pushed and popped at most once.

EXAMPLE — Next Greater Element
from typing import List

def next_greater_element(nums: List[int]) -> List[int]:
    result = [-1] * len(nums)
    stack = []  # stores indices

    for i, num in enumerate(nums):
        # While current num is greater than stack top's value
        while stack and num > nums[stack[-1]]:
            idx = stack.pop()
            result[idx] = num  # found next greater for idx
        stack.append(i)

    return result

print(next_greater_element([2, 1, 2, 4, 3]))
# [4, 2, 4, -1, -1]
