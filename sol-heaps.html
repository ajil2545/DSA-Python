SOLUTIONS 09

Heap Solutions

Priority-queue problems with heapq — a min-heap by default; negate keys when you need a max-heap.

01Kth Largest Element in an ArrayMEDIUM
Think: Keep a min-heap of size k holding the k largest values seen so far. The smallest of those k — the heap root heap[0] — is exactly the kth largest. Whenever the heap grows past k, pop the root (the smallest, so it cannot be in the top k). Sorting would be O(n log n); this is O(n log k).
1
Push each number onto the heap with heapq.heappush.
2
If len(heap) > k, heapq.heappop removes the smallest.
3
After all numbers, heap[0] is the answer.
4
Python one-liner: heapq.nlargest(k, nums)[-1] does the same size-k heap internally.
Time: O(n log k)
Space: O(k)
PYTHON — Size-k min-heap
import heapq
from typing import List


def find_kth_largest(nums: List[int], k: int) -> int:
    heap = []                        # min-heap of the k largest so far
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)      # drop the smallest — it is not top-k
    return heap[0]                   # smallest of the top k = kth largest


def find_kth_largest_short(nums: List[int], k: int) -> int:
    return heapq.nlargest(k, nums)[-1]


print(find_kth_largest([3, 2, 1, 5, 6, 4], 2))              # 5
print(find_kth_largest([3, 2, 3, 1, 2, 4, 5, 5, 6], 4))     # 4
print(find_kth_largest_short([3, 2, 1, 5, 6, 4], 2))        # 5
Python tip: once the heap holds k items, heapq.heapreplace(heap, x) pops the root and pushes x in a single O(log k) step — guard it with if num > heap[0]: heapq.heapreplace(heap, num). (heapq.heappushpop is the push-first variant: it returns x immediately if x is smaller than the root.)
02Top K Frequent ElementsMEDIUM
Think: Two phases: count, then select. collections.Counter counts in O(n). Then keep a min-heap of size k keyed by frequency, storing (count, num) tuples — tuples compare by their first item, so the least frequent element sits at the root and gets evicted.
1
counts = Counter(nums).
2
For each (num, count), push (count, num); pop when the heap exceeds k.
3
The heap now holds the k most frequent; return their nums.
4
Shortcuts: heapq.nlargest(k, counts, key=counts.get) or counts.most_common(k).
Time: O(n log k)
Space: O(n)
PYTHON — Counter + heap
import heapq
from collections import Counter
from typing import List


def top_k_frequent(nums: List[int], k: int) -> List[int]:
    counts = Counter(nums)
    heap = []                                   # (count, num), min-heap by count
    for num, count in counts.items():
        heapq.heappush(heap, (count, num))
        if len(heap) > k:
            heapq.heappop(heap)                 # evict the least frequent
    return [num for count, num in sorted(heap, reverse=True)]


def top_k_frequent_short(nums: List[int], k: int) -> List[int]:
    counts = Counter(nums)
    return heapq.nlargest(k, counts, key=counts.get)


print(top_k_frequent([1, 1, 1, 2, 2, 3], 2))        # [1, 2]
print(top_k_frequent([1], 1))                       # [1]
print(top_k_frequent_short([4, 4, 5, 5, 5, 6], 2))  # [5, 4]
print(Counter([1, 1, 1, 2, 2, 3]).most_common(2))   # [(1, 3), (2, 2)]
Python tip: The bucket-sort solution in HashMap Solutions is O(n). The heap version wins when k is small and the data is a stream you cannot index by frequency.
03K Closest Points to OriginMEDIUM
Think: We want the k smallest distances, so keep a max-heap of size k: the farthest of our current k sits on top and is evicted when something closer arrives. heapq is a min-heap only, so push the negated squared distance. No sqrt needed — squared distance preserves order.
1
For each point compute d = x*x + y*y.
2
Push (-d, x, y); if the heap size exceeds k, pop (removes the largest distance).
3
Return the points left in the heap.
Time: O(n log k)
Space: O(k)
PYTHON — Max-heap via negation
import heapq
from typing import List


def k_closest(points: List[List[int]], k: int) -> List[List[int]]:
    heap = []                                   # (-dist, x, y): max-heap by distance
    for x, y in points:
        dist = x * x + y * y                    # squared distance is enough
        heapq.heappush(heap, (-dist, x, y))
        if len(heap) > k:
            heapq.heappop(heap)                 # drop the farthest
    return [[x, y] for _, x, y in heap]


def k_closest_short(points: List[List[int]], k: int) -> List[List[int]]:
    return heapq.nsmallest(k, points, key=lambda p: p[0] ** 2 + p[1] ** 2)


print(k_closest([[1, 3], [-2, 2]], 1))                    # [[-2, 2]]
print(sorted(k_closest([[3, 3], [5, -1], [-2, 4]], 2)))   # [[-2, 4], [3, 3]]
print(k_closest_short([[3, 3], [5, -1], [-2, 4]], 2))     # [[3, 3], [-2, 4]]
Python tip: Negation is the standard Python max-heap trick: push -key, and negate again when you read it back. It works for any numeric key.
04Find Median from Data StreamHARD
Think: Split the numbers into two halves. A max-heap low holds the smaller half, a min-heap high holds the larger half. Keep them balanced so len(low) is equal to or one more than len(high). The median is then either -low[0] or the average of the two tops — O(1).
1
add_num: push onto low (negated), then move low's largest to high — this keeps every value in low ≤ every value in high.
2
If high is now bigger than low, move high's smallest back to low.
3
find_median: odd count → -low[0]; even count → average of -low[0] and high[0].
Time: add O(log n), median O(1)
Space: O(n)
PYTHON — Two heaps (MedianFinder)
import heapq


class MedianFinder:
    def __init__(self):
        self.low = []    # max-heap (values stored negated) — smaller half
        self.high = []   # min-heap                          — larger half

    def add_num(self, num: int) -> None:
        # 1) push into low, then hand low's maximum over to high
        heapq.heappush(self.low, -num)
        heapq.heappush(self.high, -heapq.heappop(self.low))
        # 2) rebalance so low has the same size or one extra
        if len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def find_median(self) -> float:
        if len(self.low) > len(self.high):
            return float(-self.low[0])
        return (-self.low[0] + self.high[0]) / 2


mf = MedianFinder()
mf.add_num(1)
mf.add_num(2)
print(mf.find_median())  # 1.5
mf.add_num(3)
print(mf.find_median())  # 2.0

mf2 = MedianFinder()
for n in [5, 15, 1, 3]:
    mf2.add_num(n)
    print(mf2.find_median())
# 5.0
# 10.0
# 5.0
# 4.0
Python tip: Always routing the new number through low into high is what keeps the halves ordered — you never need to compare num against the tops yourself.
05Merge K Sorted ListsHARD
Think: The next node of the merged list is always the smallest head among the k lists. A min-heap of the k current heads gives that in O(log k). Pop the smallest, attach it, push its next. Push (val, idx, node) tuples: if two values tie, Python compares the next item — the unique index — so it never tries to compare two ListNode objects (which would raise TypeError).
1
Push the head of every non-empty list as (node.val, i, node).
2
Use a dummy node and a tail pointer to build the result.
3
Pop the smallest, link tail.next = node, advance tail.
4
If node.next exists, push (node.next.val, i, node.next). Return dummy.next.
Time: O(N log k), N = total nodes
Space: O(k)
PYTHON — Heap of (val, idx, node)
import heapq
from typing import List, Optional


class ListNode:
    def __init__(self, val: int = 0, next: "Optional[ListNode]" = None):
        self.val = val
        self.next = next


def build_list(values: List[int]) -> Optional[ListNode]:
    dummy = tail = ListNode()
    for v in values:
        tail.next = ListNode(v)
        tail = tail.next
    return dummy.next


def to_list(head: Optional[ListNode]) -> List[int]:
    out = []
    while head:
        out.append(head.val)
        head = head.next
    return out


def merge_k_lists(lists: List[Optional[ListNode]]) -> Optional[ListNode]:
    heap = [(node.val, i, node) for i, node in enumerate(lists) if node]
    heapq.heapify(heap)                         # O(k)

    dummy = tail = ListNode()
    while heap:
        val, i, node = heapq.heappop(heap)      # smallest head overall
        tail.next = node
        tail = node
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next


lists = [build_list([1, 4, 5]), build_list([1, 3, 4]), build_list([2, 6])]
print(to_list(merge_k_lists(lists)))   # [1, 1, 2, 3, 4, 4, 5, 6]
print(to_list(merge_k_lists([])))      # []
print(to_list(merge_k_lists([None])))  # []
Python tip: The index i in the tuple is a tie-breaker. Without it, two equal values would make heapq compare ListNode objects and crash with TypeError: '<' not supported.
